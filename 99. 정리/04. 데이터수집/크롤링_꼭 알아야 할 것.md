## 0. 큰 그림 : 크롤링과 스크래핑

| 용어 | 뜻 | 도구 |
|---|---|---|
| **크롤링** | 서버에 요청해서 페이지(HTML)를 **받아오는** 것 | `requests`, `urllib`, `selenium` |
| **스크래핑** | 받아온 HTML에서 원하는 부분만 **골라내는** 것 | `BeautifulSoup` |

```
① 요청            ② 성공 확인              ③ 파싱                  ④ 골라내기              ⑤ 저장
requests.get() → status_code == 200 → BeautifulSoup(...) → select / find → DataFrame → CSV
```

브라우저도 똑같이 ①~③을 하고, 받은 HTML을 **화면으로 그려서** 보여 줄 뿐이다.
크롤링은 이걸 파이썬이 직접 하고, 화면 대신 **HTML 글자 덩어리**를 받는다.

어떤 크롤링 코드를 봐도 "지금 ①~⑤ 중 어디인가"를 먼저 찾으면 읽힌다.

## 1. requests : 페이지 요청하기

### 1-1. 요청 보내기

```python
import requests

res = requests.get("http://naver.com")      # GET 요청 : "이 페이지 주세요"
print("status_code : ", res.status_code)    # 200
```

- `requests.get(주소)` : 서버에 페이지를 요청한다. 결과는 **응답(Response) 객체**.
- `res` 안에 들어 있는 것

| 속성 | 내용 |
|---|---|
| `res.status_code` | 상태 코드 (200, 404 …) |
| `res.text` | 응답 본문(HTML)을 **문자열**로 |
| `res.content` | 응답 본문을 **bytes**로 (이미지 저장할 때 사용 → 10장) |
| `res.url` | 실제로 도착한 주소 (리다이렉트됐으면 바뀐 주소) |
| `res.json()` | 본문이 JSON이면 **딕셔너리**로 변환 (8장) |

### 1-2. 상태 코드

| 코드 | 분류 | 뜻 | 할 일 |
|---|---|---|---|
| **200** | 성공 | 정상 | 다음 단계로 |
| **403** | 4xx **클라이언트(내) 문제** | 접근 금지. 대부분 봇으로 의심받음 | headers 추가 (4장) |
| **404** | 4xx | 페이지 없음 | 주소 확인 |
| **500** | 5xx **서버 문제** | 서버 내부 오류 | 내 잘못 아님. 잠시 뒤 다시 |

```python
res = requests.get("http://yyy.tistory.com")
print("status_code : ", res.status_code)    # 404
```

**중요** : requests는 404가 와도 **에러를 내지 않는다.** 그냥 `status_code`에 404를 담아서 돌려준다.
→ 확인하지 않으면 "없는 페이지"를 열심히 파싱하고 "왜 결과가 비었지?" 하고 헤매게 된다.

### 1-3. 성공 여부 확인하는 두 가지 방법

**방법 ① if문으로 직접 비교**

```python
if res.status_code == requests.codes.ok:   # requests.codes.ok = 200 (숫자 대신 이름)
    print("정상")
else:
    print("오류 : ", res.status_code)       # 오류 :  404
```

**방법 ② raise_for_status() : 실패하면 바로 멈추기**

```python
res = requests.get("http://naver.com")
res.raise_for_status()    # 4xx/5xx면 HTTPError 발생 → 아래 줄 실행 안 됨. 200이면 그냥 통과

print("정상입니다.")
print(len(res.text))      # 216331  (HTML 글자 수)
print(res.text)           # HTML 원문 전체 (매우 길다)
```

| | if문 | raise_for_status() |
|---|---|---|
| 실패 시 | 원하는 처리를 직접 작성 | 에러를 내고 멈춤 |
| 언제 | 실패해도 계속 진행해야 할 때 | 실패하면 더 할 게 없을 때 (대부분) |

## 2. urllib : 기본 모듈로 요청하기

파이썬에 **기본 내장**된 모듈. 설치는 필요 없지만 requests보다 불편하다. 실무에서는 requests를 주로 쓴다.

### 2-1. urlopen과 bytes

```python
from urllib.request import urlopen

html = urlopen("https://www.naver.com")   # requests.get과 같은 역할
print(html.read())                         # b' <!doctype html> ... \xeb\x84\xa4\xec\x9d\xb4...'
```

- `read()`는 **bytes**(`b'...'`)를 돌려준다. 그래서 한글이 `\xeb\x84\xa4`처럼 보인다.
- 문자열로 보려면 **디코딩** : `html.read().decode("utf-8")`
- requests는 `res.text`가 알아서 문자열로 바꿔 준다. (이게 requests가 편한 이유 중 하나)

### 2-2. 에러 처리 : HTTPError vs URLError

**requests와 반대로, urllib은 404면 바로 에러를 낸다.** 그래서 `try/except`로 감싼다.

```python
from urllib.request import urlopen, HTTPError, URLError

try:
    html = urlopen("http://www.dddsdf.com/kim.html")
except HTTPError as e:          # 서버는 있는데 페이지 요청이 실패 (404 등)
    print(e)                    # HTTP Error 404: Not Found
except URLError as e:           # 서버 자체를 못 찾음 (없는 도메인, 인터넷 끊김)
    print("The server could not be found!")
else:                           # 에러가 하나도 없을 때만 실행
    print("성공")
```

| 예외 | 상황 | 예 |
|---|---|---|
| `HTTPError` | 서버에 **접속은 됐는데** 4xx/5xx 응답 | `google.com/kim.html` (구글은 있지만 페이지가 없음) |
| `URLError` | 서버에 **접속조차 못 함** | `dddsdf.com` (그런 도메인이 없음) |

**순서 주의** : `HTTPError`는 `URLError`의 한 종류(하위 클래스)다.
`URLError`를 먼저 쓰면 HTTPError까지 다 잡아 버려서 둘을 구분할 수 없다. → **좁은 것(HTTPError)부터.**

**try / except / else**

| 블록 | 언제 실행 |
|---|---|
| `try` | 일단 실행해 본다 |
| `except` | try에서 에러가 났을 때 |
| `else` | try에서 에러가 **안** 났을 때만 |

## 3. BeautifulSoup : 원하는 태그 꺼내기

`res.text`는 HTML이 **한 덩어리 글자**로 들어 있다. BeautifulSoup은 이걸 **태그 구조로 정리**해서 이름으로 찾아갈 수 있게 해 준다.

```python
# 설치 (이미 설치돼 있으면 필요 없음)
# !pip install bs4     ← 노트북 셀에서 ! 를 붙이면 터미널 명령으로 실행
```

### 3-1. 파싱하고 첫 번째 태그 찾기 : find

```python
import bs4

html_str = """<html>
                <div>hello</div>
            </html>"""

bs_obj = bs4.BeautifulSoup(html_str, "html.parser")   # "html.parser" : 파이썬 기본 해석기

print(type(bs_obj))              # <class 'bs4.BeautifulSoup'>
print(bs_obj.find("div"))        # <div>hello</div>   ← 태그 통째로
print(bs_obj.find("div").text)   # hello              ← 안쪽 글자만
```

- `find("태그")` : 조건에 맞는 **첫 번째 하나**. 없으면 `None`
- `.text` : 태그를 뺀 안쪽 **글자만**

### 3-2. 찾은 태그 안에서 다시 찾기

```python
html_str = """
<ul>
    <li>hello</li>
    <li>bye</li>
    <li>welcome</li>
</ul>
"""
bs_obj = bs4.BeautifulSoup(html_str, "html.parser")

ul = bs_obj.find("ul")    # <ul> 통째로 (안의 <li> 3개 포함)
li = ul.find("li")        # 문서 전체가 아니라 ul "안에서만" 찾기
print(li)                 # <li>hello</li>
print(li.text)            # hello
```

`find`는 문서 전체(`bs_obj`)뿐 아니라 **찾아 둔 태그(`ul`)에도** 쓸 수 있다.
→ 범위를 좁혀서 찾는 것. 7장, 10장에서 계속 쓰는 핵심 습관.

### 3-3. 전부 찾기 : find_all

```python
lis = ul.find_all("li")
print(lis)            # [<li>hello</li>, <li>bye</li>, <li>welcome</li>]
print(lis[1])         # <li>bye</li>    ← 리스트라서 인덱스로 접근
print(lis[1].text)    # bye
```

- `find_all` = `findAll` (같은 함수). `findAll`은 옛날 이름이라
  `DeprecationWarning: Call to deprecated method findAll` 경고가 뜬다. → **`find_all`로 쓰기**
- 결과 타입은 `bs4.element.ResultSet`이지만 **리스트처럼 쓰면 된다.** (하나도 없으면 `[]`)

### 3-4. class로 구분해서 찾기

```html
<ul class="greet"> <li>hello</li> <li>bye</li> <li>welcome</li> </ul>
<ul class="reply"> <li>ok</li>    <li>no</li>  <li>sure</li>    </ul>
```

```python
bs_obj.find("ul")                          # 첫 번째만 → greet
bs_obj.find_all("ul")                      # 둘 다 → [greet, reply]
bs_obj.find("ul", {"class": "reply"})      # class가 reply인 것 → reply
bs_obj.find("ul", class_="reply")          # 위와 같은 뜻
```

`class_`에 `_`가 붙는 이유 : `class`는 파이썬 예약어(클래스 만들 때 쓰는 단어)라서 변수 이름으로 못 쓴다.

### 3-5. 속성 값 꺼내기 : href

```html
<a href="http://www.naver.com/">네이버</a>
```

```python
atag = bs_obj.find("a")
print(atag)              # <a href="http://www.naver.com/">네이버</a>
print(atag["href"])      # http://www.naver.com/   ← 태그["속성명"]
print(atag.text)         # 네이버

atags = bs_obj.find_all("a")
print(atags[-1]["href"]) # http://www.facebook.com/   ← [-1] : 마지막 요소

for x in atags:          # 전부 하나씩
    print(x.text)        # 네이버 / 다음 / 구글 / 페이스북
```

| 꺼낼 것 | 코드 | 결과 |
|---|---|---|
| 태그 통째로 | `atag` | `<a href="...">네이버</a>` |
| 글자 | `atag.text` | `네이버` |
| 속성 (없으면 **에러**) | `atag["href"]` | `http://www.naver.com/` |
| 속성 (없으면 **None**) | `atag.get("href")` | `http://www.naver.com/` |

**노트북 출력 규칙** : 셀의 **마지막 줄 값만** 화면에 표시된다.

```python
type(atags)     # ← 마지막 줄이 아니라서 안 보임
atags[0].text   # ← 마지막 줄 → '네이버' 표시
```

## 4. 실전 : 네이버 검색 결과 가져오기

### 4-1. 전체 코드

```python
import requests
from bs4 import BeautifulSoup

query = "인공지능"
url = f"https://search.naver.com/search.naver?where=nexearch&sm=top_hty&fbm=0&ie=utf8&query={query}&ackey=74jg70sa"

headers = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/130.0.0.0 Safari/537.36"
    )
}

response = requests.get(url, headers=headers, timeout=10)

print("상태 코드:", response.status_code)   # 200
print("최종 URL:", response.url)
response.raise_for_status()

soup = BeautifulSoup(response.text, "html.parser")
print("페이지 제목:", soup.title.get_text(strip=True) if soup.title else "제목 없음")
print(soup.prettify()[:2000])
```

### 4-2. URL : `?` 뒤는 서버에 넘기는 조건

```
https://search.naver.com/search.naver ? where=nexearch & ... & query=인공지능 & ...
└────────── 어느 페이지 ──────────┘   └──── 조건(파라미터) : 이름=값, &로 연결 ────┘
```

- 검색어만 바꾸려면 `query=` 뒤만 바꾼다. → `f"...query={query}..."` (f-string으로 끼워 넣기)
- `sm=top_hty`, `ackey=...` 같은 나머지는 네이버가 내부적으로 쓰는 값. **몰라도 된다.**
- 출력된 최종 URL을 보면 `query=%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5`로 바뀌어 있다.
  → 주소에는 한글을 그대로 못 넣어서 requests가 **자동으로 변환(URL 인코딩)** 한 것. 같은 "인공지능"이다.

### 4-3. headers : 브라우저인 척하기

헤더 없이 보내면 서버는 `User-Agent: python-requests/2.32` 를 본다.
→ "프로그램이 왔네" → **막거나(403), 다른 페이지를 주거나, 내용을 빼고** 준다.
→ 크롬이 보내는 것과 같은 `User-Agent`를 넣는다.

- 안의 긴 문자열은 **외우지 않는다.** 내 크롬의 값은 F12 → Console → `navigator.userAgent` 로 확인할 수 있다.
- 괄호 안에서 문자열을 나란히 쓰면 **자동으로 하나로 이어 붙는다.** (긴 문자열을 여러 줄로 나눠 쓰는 방법)

### 4-4. timeout

`timeout=10` : 10초 안에 응답이 없으면 포기하고 `requests.exceptions.Timeout` 에러를 낸다.
안 쓰면 서버가 대답할 때까지 **무한정 기다릴 수 있다.**

### 4-5. 제목 꺼내기 : None 대비

```python
soup.title.get_text(strip=True) if soup.title else "제목 없음"
```

- `soup.title` : 첫 번째 `<title>` 태그
- `get_text(strip=True)` : 글자만, **앞뒤 공백 제거**
- `<title>`이 없으면 `soup.title`이 `None` → `None.get_text()`는 **에러**
  → `A if 조건 else B` 로 **"있는지 먼저 확인하고 꺼낸다."** 웹페이지는 언제든 바뀌기 때문에 크롤링의 기본 습관.

### 4-6. prettify

`soup.prettify()` : HTML을 **들여쓰기해서** 보기 좋게. `[:2000]` → 앞 2000글자만.

### 4-7. 페이지의 모든 링크 꺼내기

```python
links = soup.select("a")                    # 페이지 안의 <a> 전부 (= find_all("a"))
print(f"발견한 링크 수:{len(links)}")        # 478

for link in links:
    title = link.get_text(" ", strip=True)  # 글자
    href = link.get("href")                 # 주소. 없으면 None (에러 안 남)

    if title and href and href.startswith("http"):
        print("제목:", title)
        print("링크:", href)
        print("=" * 60)
```

**`get_text(" ", strip=True)`**

| 옵션 | 뜻 | 예 (`<a><span>쇼핑</span><span>새 창 열림</span></a>`) |
|---|---|---|
| 없음 | 그대로 | `쇼핑새 창 열림` |
| `" "` | 안쪽 태그 사이를 **공백 한 칸**으로 | `쇼핑 새 창 열림` |
| `strip=True` | 앞뒤 공백 제거 | |

**`link["href"]` 대신 `link.get("href")`를 쓴 이유**
아이콘 링크 등 `href`가 없는 `<a>`도 있다. `link["href"]`는 그때 `KeyError`로 멈춘다. `.get()`은 `None`을 돌려준다.

**if 조건 세 개의 뜻**

| 조건 | 걸러내는 것 |
|---|---|
| `title` | 빈 문자열 `""` → False → 글자 없는 링크(아이콘) 제외 |
| `href` | `None` → False → 주소 없는 링크 제외 |
| `href.startswith("http")` | `"#"`, `"javascript:..."` 같은 내부 동작용 링크 제외 |

`and`는 **앞이 False면 뒤를 검사하지 않는다.** 그래서 `href`가 `None`일 때 `href.startswith()`가 실행되지 않아 에러가 안 난다. → **순서가 중요.**

> 참고 : 네이버는 검색 결과 일부를 자바스크립트로 그리고 class 이름도 자주 바꾼다.
> 그래서 링크 개수나 구조는 실행할 때마다 달라질 수 있다.

## 5. CSS 선택자 : select / select_one

### 5-1. 문법

| 선택자 | 뜻 | 예 |
|---|---|---|
| `a` | 태그 이름 | 모든 `<a>` |
| `.description` | **점(.) = class** | `class="description"` |
| `#main` | **샵(#) = id** | `id="main"` |
| `p.summary` | 태그 + class | `<p class="summary">` 만 |
| `h2 a` | **띄어쓰기 = 안에 있는(자손)** | `<h2>` 안 어딘가의 `<a>` |
| `ul > li` | **`>` = 바로 아래 자식** | `<ul>` 바로 아래 `<li>` |
| `a[href]` | 속성이 있는 | `href`가 있는 `<a>` |
| `meta[property="og:title"]` | 속성 값이 같은 | `property="og:title"` 인 `<meta>` |
| `a[href*="nid"]` | 속성 값에 **포함** (`*=`) | 주소에 `nid`가 들어간 `<a>` |

### 5-2. find 계열과 대응

| find 계열 | select 계열 | 결과 | 없으면 |
|---|---|---|---|
| `find("ul", class_="reply")` | `select_one("ul.reply")` | 첫 번째 하나 | `None` |
| `find_all("li")` | `select("li")` | 전부 (리스트) | `[]` |

select가 더 많이 쓰이는 이유 : `"dl.summary_list div.sort"`처럼 **여러 단계를 한 줄로** 쓸 수 있다.

### 5-3. 연습

```html
<div class="search-result">
    <h2><a href="https://example.com/ai">인공지능 기술 동향</a></h2>
    <p class="description">최근 인공지능 기술의 발전과 산업 적용 사례를 소개합니다.</p>
</div>
```

```python
soup = BeautifulSoup(html, "html.parser")

result = soup.select_one(".search-result")           # 검색 결과 한 건 상자

title_tag = result.select_one("h2 a")                # 상자 안의 <h2> 안의 <a>
title = title_tag.get_text(" ", strip=True)          # 인공지능 기술 동향
link = title_tag.get("href")                         # https://example.com/ai

description = result.select_one(".description").get_text(strip=True)
```

`result.select_one(...)` : 문서 전체가 아니라 **result 상자 안에서만** 찾는다. (3-2와 같은 원리)

**⚠ 이 셀에서 생긴 문제** : `soup = BeautifulSoup(html, ...)` 로 **같은 변수 이름**을 썼다.
→ 4장에서 받아 둔 네이버 페이지 soup이 연습용 HTML로 **덮어써져서 사라졌다.**
→ 그래서 6장에서 네이버를 다시 요청해야 했다. 연습용은 `practice_soup`처럼 **다른 이름**을 쓰면 피할 수 있다.

## 6. 검색 결과를 CSV로 저장

### 6-1. 다시 요청

5장에서 soup이 덮어써졌으므로, 4-1과 같은 코드로 네이버 검색 페이지를 다시 받아 `soup`을 되돌린다.

### 6-2. 리스트 → DataFrame → CSV

```python
import pandas as pd

results = []                                     # 링크 하나당 딕셔너리 1개 → 표의 "행"

for link_tag in soup.select("a"):
    title = link_tag.get_text(" ", strip=True)
    href = link_tag.get("href", "")              # 없으면 None 대신 "" → startswith 에러 안 남

    if title and href.startswith("http"):
        results.append({                         # 딕셔너리의 키 → 표의 "열 이름"
            "검색어": query,
            "제목": title,
            "링크": href
        })

df = pd.DataFrame(results)                       # 딕셔너리 리스트 → 표

if not df.empty:                                 # 비어 있지 않을 때만
    df = df.drop_duplicates(subset=["링크"])     # 링크가 같은 행은 첫 번째만 남김

df.to_csv("naver_search_results.csv", index=False, encoding="utf-8-sig")
print(df.head(10))
```

| 코드 | 뜻 |
|---|---|
| `link_tag.get("href", "")` | 없을 때 돌려줄 기본값을 `""`로 지정. 4-7에서는 `None`이라 `href and`를 따로 검사했다 |
| `results.append({...})` | 모으기만 하고, 표는 **for문이 끝난 뒤 한 번만** 만든다 |
| `drop_duplicates(subset=["링크"])` | "링크" 열 기준으로 중복 제거 |
| `if not df.empty` | 결과가 0건일 때 빈 표에서 "링크" 열을 찾다가 에러 나는 것 방지 |
| `index=False` | 0, 1, 2… 행 번호는 저장하지 않음 |
| `encoding="utf-8-sig"` | 엑셀에서 열어도 **한글이 안 깨짐** (맨 앞에 BOM 표시를 넣음) |

### 6-3. 개발자도구에서 복사한 선택자 쓰기

F12 → 원하는 요소 **우클릭** → Copy → **Copy selector**

result = soup.select("head > meta:nth-child(4)")   # <head> 바로 아래 자식 중 4번째인 <meta>
print(result)                    # [<meta content="인공지능 : 네이버 검색" property="og:title"/>]

- **⚠ `nth-child(4)`는 순서 번호**라서, 사이트가 태그를 하나만 추가해도 다른 태그를 가리킨다.
  → 속성으로 찾는 게 안전하다 : `soup.select_one('meta[property="og:title"]')`

## 7. 네이버 날씨 : 원하는 영역만 골라내기

### 7-1. 화면과 태그 대응

| 화면 | HTML | 선택자 |
|---|---|---|
| 21.3° | `<div class="temperature_text">` | `.temperature_text` |
| 어제보다 6.4° 높아요 맑음 | `<p class="summary">` | `p.summary` |
| 체감 / 습도 / 바람 | `<dl class="summary_list">` 안의 `<div class="sort">` | `dl.summary_list div.sort` |
| 위 전부를 감싼 박스 | `<div class="weather_info">` | `div.weather_info` |

**찾는 방법** : F12 → 왼쪽 위 화살표(`Ctrl+Shift+C`) → 화면에서 클릭 → 그 태그의 `class` 확인 → select에 넣기

### 7-2. 코드

```python
url = "https://search.naver.com/search.naver?query=날씨"
headers = {"User-Agent": "Mozilla/5.0 ... Chrome/155.0.0.0 Safari/537.36"}

# 요청 → .text → 파싱을 한 줄에
soup = BeautifulSoup(requests.get(url, headers=headers, timeout=10).text, "html.parser")

# 1) 현재 온도
temp = soup.select_one(".temperature_text").get_text(strip=True).replace("현재 온도", "")
print("현재 온도:", temp)               # 21.3°

# 2) 요약
summary = soup.select_one("p.summary").get_text(" ", strip=True)
print("요약:", summary)                 # 어제보다 6.4° 높아요 맑음

# 3) 체감·습도·바람
for item in soup.select("dl.summary_list div.sort"):
    name = item.select_one("dt.term").get_text(strip=True)     # 체감
    value = item.select_one("dd.desc").get_text(strip=True)    # 21.3°
    print(name, ":", value)
```

### 7-3. 한 줄씩 짚기

**한 줄 요청** : `requests.get(...)` → `.text` → `BeautifulSoup(...)` 를 한 번에.
짧지만 응답을 변수에 저장하지 않아서 **상태 코드를 확인할 수 없다.** 안 될 때 원인 찾기가 어렵다.

**`.replace("현재 온도", "")` 를 쓴 이유**
실제 HTML은 `<strong><span class="blind">현재 온도</span>21.3°</strong>` 이다.
`class="blind"` : 화면에는 안 보이고 **시각장애인용 화면 읽기 프로그램만 읽는** 글자.
`get_text`는 안 보이는 글자까지 가져오므로 `"현재 온도21.3°"`가 된다 → replace로 지운다.

**`get_text(" ", strip=True)`**
`" "`가 없으면 `"어제보다6.4°높아요맑음"`. 조각 사이를 한 칸씩 띄워서 읽기 좋게 만든다.

**dt / dd 짝 맞추기**

```html
<dl class="summary_list">
    <div class="sort"> <dt class="term">체감</dt> <dd class="desc">21.3°</dd> </div>
    <div class="sort"> <dt class="term">습도</dt> <dd class="desc">45%</dd>   </div>
    <div class="sort"> <dt class="term">남서풍</dt> <dd class="desc">2.1m/s</dd> </div>
</dl>
```

- `<dt>` = 이름, `<dd>` = 값. 한 쌍이 `<div class="sort">` 하나에 들어 있다.
- `soup`이 아니라 **`item`(상자 하나) 안에서** dt와 dd를 찾는다 → 이름과 값이 **항상 짝이 맞는다.**
- 만약 `soup.select("dt.term")`, `soup.select("dd.desc")`를 따로 모으면, 중간에 하나라도 빠졌을 때 짝이 밀린다.

### 7-4. 날씨 박스 통째로 가져오기 : 잘못된 페이지에서 찾은 실수

```python
# ✗ None이 나왔던 코드
bs_obj = BeautifulSoup(res.text, "html.parser")
weather = bs_obj.select_one("div.weather_info")   # None
```

`res`는 1장에서 만든 `requests.get("http://naver.com")` = **네이버 메인** 페이지.
메인에는 날씨 박스가 없으니 못 찾아서 `None`.

```python
# ✓ 날씨 검색 페이지가 담긴 soup에서 찾기
weather = soup.select_one("div.weather_info")
```

**교훈** : `None`이 나오면 선택자보다 먼저 **"지금 어느 페이지의 HTML에서 찾고 있나"** 를 확인한다.
노트북은 앞에서 만든 변수가 계속 남아 있어서 이런 실수가 잘 생긴다.

### 7-5. 같은 일을 find / find_all로

```python
dl = weather.find("dl", {"class": "summary_list"})   # = weather.select_one("dl.summary_list")

if dl:                                    # None이 아닐 때만 (None이면 dl.find_all에서 에러)
    divs = dl.find_all("div")             # [체감 상자, 습도 상자, 바람 상자]
    print(len(divs))                      # 3
    print(type(dl))                       # <class 'bs4.element.Tag'> : 태그 하나

    for div in divs:
        dt_tag = div.find("dt")
        if dt_tag:
            print(dt_tag.get_text(strip=True), end=" ")   # end=" " : 줄바꿈 대신 공백
        dd_tag = div.find("dd")
        if dd_tag:
            print(dd_tag.get_text(strip=True))            # 기본은 줄바꿈
else:
    print("날씨 정보를 찾을 수 없습니다.")
```

**`print(..., end=" ")`** : print는 원래 끝에 줄바꿈을 넣는다. `end=" "`로 바꾸면 다음 print가 **같은 줄에** 이어진다.
→ `체감 21.3°` 가 한 줄에 나온다.

**`if 태그:` 습관** : 찾은 결과가 `None`일 수 있으면 꺼내기 전에 반드시 확인한다.
네이버가 class 이름을 바꾸면 `'NoneType' object has no attribute 'get_text'` 에러가 난다.

## 8. 네이버 증권 : HTML에 숫자가 없는 페이지 (API)

### 8-1. 날씨와 뭐가 다를까

|  | 네이버 날씨 | 네이버 증권 |
|---|---|---|
| requests로 받은 HTML | 숫자가 **들어 있음** | **빈 틀만** 있음 (숫자 0개) |
| 숫자가 오는 곳 | HTML 안 | 자바스크립트가 따로 부르는 **데이터 주소(API)** |
| 꺼내는 방법 | `BeautifulSoup` + `select_one` | `res.json()` → 딕셔너리 |

요즘 페이지는 **① HTML 뼈대**를 먼저 보내고, **② 브라우저가 자바스크립트로 숫자를 따로 받아와 채운다.**
requests는 ①만 받는다. 그래서 BeautifulSoup으로 찾으면 `None`이다.
→ ②에서 자바스크립트가 부르는 **데이터 주소에 직접 요청**하면 숫자만 깔끔하게 받을 수 있다.

### 8-2. API 주소 찾는 법

1. F12 → **Network** 탭
2. 새로고침 (F5)
3. 목록에서 주소에 `api`가 들어간 요청 클릭
4. **Response** 탭에서 원하는 숫자가 보이면 → 그 주소를 사용

### 8-3. 코드

```python
code = "005930"   # 종목코드 (삼성전자)
url = f"https://m.stock.naver.com/api/stock/{code}/integration"

res = requests.get(url, headers=headers, timeout=10)
data = res.json()                       # JSON 글자 → 파이썬 딕셔너리

print(f"종목명: {data['stockName']} ({code})")   # 삼성전자 (005930)
print("-" * 30)

wanted = ["전일", "고가", "거래량", "시가", "저가", "대금"]
for info in data["totalInfos"]:          # info = {"key": "전일", "value": "214,500"}
    if info["key"] in wanted:
        print(f"{info['key']}: {info['value']}")
```

**JSON 모양**

```
{
  "stockName": "삼성전자",                         ← data["stockName"]
  "totalInfos": [                                  ← data["totalInfos"] : 리스트
      {"key": "전일", "value": "214,500"},         ← info["key"], info["value"]
      {"key": "시가", "value": "207,000"},
      ...  (PER, 시총, 52주 최고 등 18개)
  ]
}
```

- **JSON** : 데이터만 담은 글자 형식. 딕셔너리·리스트와 모양이 같다. HTML이 아니라 BeautifulSoup이 필요 없다.
- `딕셔너리["키"]` 로 값을, `리스트`는 for문으로 하나씩.
- `wanted`에 원하는 항목만 넣고 `in`으로 골라낸다. 화면의 "거래대금"은 데이터에서는 `"대금"`이다.
  → **화면 글자와 데이터 이름이 다를 수 있으니 Response에서 실제 이름을 확인.**

**출력**

```
종목명: 삼성전자 (005930)
------------------------------
전일: 214,500
시가: 207,000
고가: 215,500
저가: 203,500
거래량: 25,059,542
대금: 5조 2,533억
```

### 8-4. ⚠ robots.txt

네이버 증권은 `robots.txt`에 `Disallow: /` (전체 자동 수집 금지)를 걸어 두었다.
→ 실습으로 가끔 한 번 실행하는 정도만. 반복문으로 여러 종목을 자동 수집하지 않는다.
→ 주가를 제대로 모으려면 공공데이터포털 **"금융위원회_주식시세정보" API** (공식 경로)

## 9. Selenium : 진짜 브라우저 조종하기

### 9-1. 언제 쓰나

|  | requests + BeautifulSoup | Selenium |
|---|---|---|
| 하는 일 | HTML 원본(뼈대)만 받음 | **진짜 크롬 창을 띄워서** 사람처럼 조종 |
| 자바스크립트 | 실행 안 함 | 실행함 → 나중에 그려지는 내용도 보임 |
| 클릭·입력 | 못 함 | `click()`, `send_keys()` |
| 속도 | 빠름 | 느림 |

**고르는 순서**
1. requests로 받아서 원하는 글자가 있는지 본다 : `"원하는글자" in res.text`
2. 있으면 → requests + BeautifulSoup
3. 없는데 F12 Network에 API가 보이면 → API 직접 요청 (8장)
4. 클릭·입력이 필요하거나 API가 안 보이면 → Selenium

### 9-2. 크롬 띄우기

```python
# !pip install selenium
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
import time

service = Service()                          # ChromeDriver 서비스 (경로를 비우면 자동으로 찾아/내려받음)
options = webdriver.ChromeOptions()          # 크롬 옵션 (창 크기, 화면 없이 실행 등. 지금은 기본값)
driver = webdriver.Chrome(service=service, options=options)   # ← 이 줄에서 크롬 창이 뜬다

driver.get("http://naver.com")               # 주소창에 입력하고 Enter 친 것과 같음
```

```
파이썬 코드  →  ChromeDriver (통역사)  →  크롬 브라우저
```

| 이름 | 역할 |
|---|---|
| `webdriver` | 브라우저를 실행하고 제어하는 기능 |
| `ChromeDriver` | 파이썬 명령을 크롬이 알아듣게 전달하는 프로그램 |
| `Service()` | ChromeDriver를 실행·관리 |
| `driver` | 크롬 창을 조종하는 **리모컨** |

**⚠ `InvalidSessionIdException`**
크롬 창을 직접 닫거나 `driver.quit()`을 하면 리모컨 연결이 끊긴다.
그 뒤에 `driver`로 명령하면 이 에러가 난다. → **driver를 만드는 셀을 다시 실행.**

### 9-3. 찾고, 입력하고, 키 누르기

```python
from selenium.webdriver.common.by import By      # 무엇으로 찾을지
from selenium.webdriver.common.keys import Keys  # 특수키

element = driver.find_element(By.ID, "query")    # 네이버 검색창 <input id="query">
element.send_keys("컴퓨터")                       # 키보드로 입력
element.send_keys(Keys.ENTER)                    # Enter → 검색 실행
```

**By 종류**

| By | 찾는 기준 | 예 |
|---|---|---|
| `By.ID` | id | `By.ID, "query"` |
| `By.CLASS_NAME` | class **하나** | `By.CLASS_NAME, "tit-g"` |
| `By.CSS_SELECTOR` | CSS 선택자 (5장 문법 그대로) | `By.CSS_SELECTOR, "li .tit-g"` |
| `By.TAG_NAME` | 태그 이름 | `By.TAG_NAME, "img"` |

**Keys** : `ENTER`, `TAB`, `ESCAPE`, `ARROW_DOWN` 등 글자가 아닌 키

**BeautifulSoup과 Selenium 대응**

| | BeautifulSoup | Selenium |
|---|---|---|
| 하나 | `select_one(...)` → 없으면 **None** | `find_element(By..., ...)` → 없으면 **에러** (`NoSuchElementException`) |
| 전부 | `select(...)` | `find_elements(By..., ...)` (s가 붙음) → 없으면 `[]` |
| 글자 | `.get_text()` | `.text` |
| 속성 | `.get("src")` | `.get_attribute("src")` |

## 10. MiniPrj : 다음 영화 순위 TOP5 (5년치)

2022~2026년 연도별 영화 순위 TOP5의 **제목, 누적 관객, 포스터**를 수집한다.

### 10-1. 페이지 열기

```python
url = "https://search.daum.net/search?w=tot&q=2026%EB%85%84%EC%98%81%ED%99%94%EC%88%9C%EC%9C%84&DA=MOR&rtmaxcoll=MOR"
driver.get(url)
time.sleep(3)    # 자바스크립트가 영화 목록을 다 그릴 때까지 기다리기
```

- `q=` 뒤의 `%EB%85%84...` = `"년영화순위"`를 주소용으로 변환(URL 인코딩)한 것 (4-2와 같음)
- `time.sleep(3)` : `driver.get()`은 HTML 뼈대가 오면 바로 다음 줄로 넘어간다. 영화 목록은 **그 뒤에** 자바스크립트가 채우므로 기다려야 한다. 안 기다리면 `NoSuchElementException`.

### 10-2. 전체 코드 (고친 버전)

```python
import requests
from IPython.display import display, Image

for year in range(2022, 2027):                     # 2022 ~ 2026 (끝 숫자 2027은 포함 안 함)
    try:
        url = f"https://search.daum.net/search?w=tot&q={year}년영화순위&DA=MOR&rtmaxcoll=MOR"
        driver.get(url)
        time.sleep(3)
        print(f"===== {year}년 =====")
    except Exception as e:
        print(e)
        continue                                   # 페이지를 못 열었으면 이번 연도는 건너뛰기

    # ↓ try/except와 같은 높이 (for year 바로 안)
    movies = driver.find_elements(By.CSS_SELECTOR, 'c-list-doc[data-title="실시간 예매율"] li')

    for idx, movie in enumerate(movies):
        if idx == 5:                               # 0~4 → 5편까지만
            break

        title = movie.find_element(By.CSS_SELECTOR, ".tit-g").text          # 제목
        audience = movie.find_element(By.CSS_SELECTOR, ".conts-desc").text  # 누적 관객

        img_url = movie.find_element(By.CSS_SELECTOR, "img").get_attribute("src")
        img_url = img_url.replace(".fwebp", "")    # webp 대신 jpg로 받기

        res = requests.get(img_url, timeout=10)
        with open(f"{year}_{idx + 1}.jpg", "wb") as f:
            f.write(res.content)

        print(title, "->", audience)
        display(Image(url=img_url, width=120))
```

### 10-3. ⚠ 노트북에 저장된 코드의 들여쓰기 문제

지금 노트북의 이 셀은 `movies = ...`부터 끝까지가 **`except` 블록 안**에 들어가 있다.

```python
    except Exception as e:
        print(e)
        movies = driver.find_elements(...)    # ← 에러가 났을 때만 실행됨
        for idx, movie in enumerate(movies):
            ...
```

→ 정상일 때는 수집을 **하나도 안 한다.** 노트북에 보이는 25편 출력은 **들여쓰기가 맞던 이전 실행 결과**가 남아 있는 것.
→ 위 10-2처럼 한 단계 내어 쓴다. 파이썬은 **들여쓰기가 곧 "어느 블록 안인가"** 라서, 코드가 같아도 위치가 다르면 동작이 완전히 달라진다.

### 10-4. 한 줄씩 짚기

**`range(2022, 2027)`** : 끝 숫자는 포함하지 않는다 → 2022, 2023, 2024, 2025, 2026 (5번)

**f-string 주소** : `{year}` 자리에 연도가 들어간다. 한글은 크롬이 알아서 인코딩한다.

**`time.sleep(3)` 의 두 가지 역할**
① 페이지가 다 그려질 때까지 기다리기 ② 서버에 너무 빠르게 연속 요청하지 않기 (매너)

**선택자 `'c-list-doc[data-title="실시간 예매율"] li'`**

| 조각 | 뜻 |
|---|---|
| `c-list-doc` | 태그 이름 (다음이 만든 특수 태그) |
| `[data-title="실시간 예매율"]` | 속성 값이 "실시간 예매율"인 것 → 여러 목록 중 이 목록만 |
| (띄어쓰기) `li` | 그 안에 있는 `<li>` = 영화 한 편 |

`find_elements` (s 있음) → 영화 전부를 리스트로.

**`enumerate` + `break`**

```python
for idx, movie in enumerate(movies):   # idx = 0, 1, 2 … 번호 / movie = 영화
    if idx == 5:                        # 6번째(idx 5)가 되면
        break                           # 반복을 완전히 끝냄
```

`movies[:5]` 로 써도 같다 : `for idx, movie in enumerate(movies[:5]):`

**`movie.find_element(...)`** : `driver`가 아니라 **`movie`(영화 한 편) 안에서** 찾는다.
→ 제목·관객·포스터가 항상 같은 영화의 것으로 짝이 맞는다. (7-3 dt/dd와 같은 원리)

**`.text` vs `.get_attribute("src")`**
이미지는 글자가 없다. `<img src="주소">`의 **src 속성**에 이미지 주소가 들어 있다.

**`.replace(".fwebp", "")`** : 주소 속 `.fwebp` = "webp 형식으로 달라"는 표시. 지우면 서버가 jpg로 보내 준다.

**이미지 저장**

```python
res = requests.get(img_url, timeout=10)              # 이미지 주소로 요청
with open(f"{year}_{idx + 1}.jpg", "wb") as f:       # 2022_1.jpg, 2022_2.jpg …
    f.write(res.content)
```

| 코드 | 뜻 |
|---|---|
| `"wb"` | **w**rite **b**inary : bytes 그대로 쓰기 (그림은 글자가 아니니까) |
| `res.content` | 응답을 **bytes**로. `res.text`(글자)로 쓰면 그림이 깨진다 |
| `with open(...) as f:` | 블록이 끝나면 **파일을 자동으로 닫아 줌** |
| `idx + 1` | idx는 0부터 → 파일 이름은 1부터 |

**`display(Image(url=img_url, width=120))`** : 노트북 출력 칸에 포스터를 폭 120으로 보여 준다.
(텍스트 출력에서는 `<IPython.core.display.Image object>`로 보인다)

**`except Exception as e`** : `Exception`은 거의 모든 에러를 잡는 그물. `e`는 에러 메시지.

## 11. 에러 모음 : 증상 → 원인 → 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `status_code` 403 | 봇으로 의심받음 | headers에 User-Agent 추가 |
| `status_code` 404 | 페이지 없음 | 주소 확인, `res.url` 출력 |
| `HTTPError` (urllib) | 서버는 있는데 4xx/5xx | 주소 확인 |
| `URLError` (urllib) | 서버를 못 찾음 | 도메인 오타, 인터넷 연결 |
| `requests.exceptions.Timeout` | timeout 초 안에 응답 없음 | 잠시 뒤 다시, timeout 늘리기 |
| `'NoneType' object has no attribute 'get_text'` | `select_one` / `find`가 못 찾았는데 꺼냄 | ① 지금 어느 페이지에서 찾는지 확인 ② F12로 class 다시 확인 ③ `if 태그:` |
| `KeyError: 'href'` | `태그["href"]`인데 속성이 없음 | `태그.get("href")` |
| `IndexError: list index out of range` | `select` 결과가 `[]`인데 `[0]` | 선택자 확인, `if 결과:` |
| `DeprecationWarning: findAll` | 옛날 이름 | `find_all` |
| 200인데 원하는 내용이 없음 | 자바스크립트로 나중에 그려짐 | F12 Network에서 API 찾기 또는 Selenium |
| `NoSuchElementException` (Selenium) | 페이지가 덜 그려짐 / 이름 틀림 | `time.sleep()`, F12로 다시 확인 |
| `InvalidSessionIdException` (Selenium) | 크롬 창을 닫음 | driver 만드는 셀 다시 실행 |
| 앞에서 되던 soup이 이상함 | 같은 변수 이름으로 덮어씀 | 연습용은 다른 변수 이름 |
| 코드는 맞는데 결과가 안 나옴 | 들여쓰기로 다른 블록 안에 들어감 | 들여쓰기 확인 (10-3) |
| 어제 되던 코드가 오늘 안 됨 | 사이트가 class 이름 등을 바꿈 | F12로 다시 확인 |

**안 될 때 확인 순서** : ① 상태 코드 → ② 원하는 글자가 HTML에 있나 → ③ 어느 페이지(변수)에서 찾고 있나 → ④ 선택자가 맞나

## 12. 한눈에 요약

**도구 고르기**

| 상황 | 도구 |
|---|---|
| 원하는 내용이 HTML에 있다 | `requests` + `BeautifulSoup` |
| HTML에 없고, F12 Network에 API가 보인다 | `requests` + `res.json()` |
| 클릭·입력·로그인이 필요하다 | `Selenium` |

**자주 쓴 코드**

| 하고 싶은 것 | requests / BeautifulSoup | Selenium |
|---|---|---|
| 페이지 열기 | `requests.get(url, headers=, timeout=)` | `driver.get(url)` |
| 성공 확인 | `res.status_code`, `res.raise_for_status()` | - |
| 파싱 | `BeautifulSoup(res.text, "html.parser")` | - |
| 하나 찾기 | `select_one("css")` / `find("태그")` | `find_element(By.CSS_SELECTOR, "css")` |
| 전부 찾기 | `select("css")` / `find_all("태그")` | `find_elements(By.CSS_SELECTOR, "css")` |
| 글자 | `.get_text(" ", strip=True)` | `.text` |
| 속성 | `.get("href")` | `.get_attribute("src")` |
| 입력 / 키 | - | `.send_keys("글자")`, `.send_keys(Keys.ENTER)` |
| 저장 | `pd.DataFrame(리스트).to_csv(..., encoding="utf-8-sig")` | |

**꼭 지킬 습관**
- 찾은 결과는 **None / 빈 리스트인지 먼저 확인**하고 꺼낸다.
- 큰 상자를 먼저 찾고, **그 상자 안에서** 세부 항목을 찾는다. (짝이 맞는다)
- 순서 번호(`nth-child`)보다 **class·속성**으로 찾는다.
- `robots.txt`를 확인하고, 반복 요청 사이에는 `time.sleep()`을 넣는다.
- 비밀번호는 코드에 쓰지 않는다. (`getpass()` 사용)
