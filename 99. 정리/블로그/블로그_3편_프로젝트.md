## 1. 프로젝트 소개 : 나의 입출금 시스템

2편에서 배운 pandas 기능을 한 번에 써보기 위해 **통장 거래 내역을 분석하는 가계부 프로젝트**를 진행했습니다. 1~3월 거래 내역 18건을 데이터프레임으로 만들고, 아래 세 가지 질문에 답하는 것이 목표였어요.

1. 3개월 동안 총 수입 · 지출 · 남은 금액은 얼마인가?
2. 어떤 항목에 가장 많이 썼는가?
3. 월별로 얼마씩 남았는가?

데이터는 [날짜, 구분, 항목, 금액] 형식으로 만들고, 금액은 항상 양수로 두되 수입인지 지출인지는 '구분' 열로 나누는 규칙을 정했습니다. 처음에 데이터 규칙을 분명하게 정해 두니까 뒤에서 분석할 때 훨씬 편했어요.

## 2. 분석 과정

단계별로 이렇게 진행했습니다.

- **마스크 필터링**으로 수입 데이터와 지출 데이터 나누기
- **apply**로 10만 원 이상 지출에 '큰 지출' 표시 붙이기
- **isin**으로 식비·쇼핑처럼 줄일 수 있는 지출만 골라 보기
- **groupby + sort_values**로 항목별 지출 순위 만들기
- **pivot_table**로 월별 수입 · 지출 · 남은 금액 요약표 만들기
- 그래프는 PNG 이미지로, 요약표는 CSV 파일로 저장하기

분석해 보니 3개월 동안 수입 600만 원 중 371만 원을 지출해서 229만 원이 남았고, 지출 1위는 역시 **월세(180만 원)**였습니다. 월별로 보면 3월에 가장 많이 남았고요. 숫자로 정리해서 보니까 "어디서 아껴야 하는지"가 바로 보이더라고요.

## 3. 데이터 검증 : 믿을 수 있는 데이터 만들기

분석이 끝난 뒤에는 실제 가계부 앱의 데이터 처리 부분처럼, 사용자가 입력하거나 CSV로 올린 데이터를 **검증**하는 단계도 연습했습니다.

- 필수 열(날짜, 구분, 항목, 금액)이 모두 있는가?
- 날짜가 실제 존재하는 'YYYY-MM-DD' 형식인가?
- 구분이 '수입' 또는 '지출'인가?
- 항목 이름이 1~40글자 사이인가?
- 금액이 1원 이상, 정해진 최대 금액 이하인가?
- 전체 행 수가 제한을 넘지 않는가?

1편의 영화관 프로젝트에서 입력값 검증을 처음 배웠다면, 여기서는 그걸 데이터 전체에 적용해 본 셈이에요. 금융 데이터에서는 "분석"만큼 **"데이터를 믿을 수 있게 만드는 것"**이 중요하다는 걸 몸으로 배웠습니다.

## 4. 직접 부딪히며 알게 된 것들

프로젝트를 하면서 헷갈렸던 점을 따로 정리해 뒀는데, 직접 실수하고 고친 것들이라 오래 기억에 남을 것 같아요.

- 날짜는 처음에 문자열이라서 `pd.to_datetime()`으로 바꿔야 월을 꺼낼 수 있다
- 필터링한 데이터에 새 열을 추가할 땐 `.copy()`를 붙여야 경고가 안 난다
- `groupby` 할 때는 `['금액']`처럼 계산할 열을 먼저 골라야 한다
- `savefig()`는 `show()`보다 먼저! 반대로 하면 빈 그림이 저장된다
- 엑셀에서 열 CSV는 `encoding='utf-8-sig'`로 저장해야 한글이 안 깨진다
- `merge`의 기본값은 inner join이라 한쪽에만 있는 데이터는 사라진다
- 기준값(10만 원)은 변수로 한 번만 정해 두면 나중에 한 곳만 고치면 된다

## 5. Streamlit으로 주식 차트 웹페이지 만들기

분석 결과를 나만 보는 게 아니라 다른 사람도 볼 수 있게 **Streamlit**으로 웹 화면을 만드는 것도 배웠습니다. Streamlit은 파이썬 코드만으로 웹 페이지를 만들 수 있는 도구예요.

텍스트 출력, 데이터 표, 버튼·입력창 같은 기본 UI, 차트, 파일 업로드를 차례로 배운 뒤, **주식 차트 검색 페이지**를 만들었습니다. 왼쪽 사이드바에 조회 시작일과 종목코드(예: 삼성전자 005930)를 입력하면, FinanceDataReader로 주가 데이터를 가져와 차트를 그려주는 페이지예요.

Streamlit은 사용자가 값을 바꿀 때마다 **파일 전체를 위에서 아래로 다시 실행**한다는 개념이 처음엔 낯설었는데, 오히려 그 덕분에 복잡한 이벤트 처리 없이 위에서 아래로 읽으면 되는 구조라 이해하기 쉬웠습니다. 마지막에는 글꼴을 선택하고 그래프를 바꿔 볼 수 있는 대시보드도 만들어 봤어요. 파이썬 코드 몇십 줄로 웹 페이지가 뜨는 걸 보니 정말 뿌듯했습니다.
