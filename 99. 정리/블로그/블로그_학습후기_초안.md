## 2. 첫 미니 프로젝트 - 영화관 예매 프로그램

문법을 배운 직후에 바로 미니 프로젝트를 진행했습니다. 영화 목록을 보여주고, 영화를 고르고, 인원 수를 입력받고, 할인 쿠폰을 적용해서 최종 결제 금액을 출력하는 콘솔 프로그램이에요.

여기서 제일 많이 배운 건 **"사용자는 내 예상대로 입력하지 않는다"** 는 점이었습니다.
인원 수에 `abc`나 `-1`, `0`을 넣는 경우를 막으려고 `while True` 반복문과 `isdigit()`으로 입력 검증을 넣었고, 쿠폰 코드는 `strip().upper()`로 공백과 대소문자를 정리한 뒤 딕셔너리에서 찾도록 만들었어요. 단순해 보이는 프로그램인데도 예외 상황을 생각하다 보니 꽤 고민할 거리가 많았습니다.

## 3. 금융 알고리즘을 파이썬으로 풀어보기

금융권 취업이 목표다 보니 이 파트가 특히 재미있었습니다. 실제 투자·금융에서 쓰이는 계산을 파이썬 코드로 직접 구현했어요.

- 매수가와 현재가로 **수익률**을 계산하고 A/B/C/D 등급으로 분류하기
- 목표 수익률에 맞는 **목표 매도가** 계산
- 수수료와 세금을 반영한 **손익분기 매도가** 계산
- 원금과 연 수익률로 **월 복리** 계산하기

"손익분기점 = 매수가 ÷ (1 − 수수료율 − 세율)" 같은 공식을 코드로 옮기면서, 그동안 막연하게 알던 금융 개념을 숫자로 정확히 이해하게 된 게 가장 큰 수확이었습니다.

## 4. 2주차 - pandas로 데이터 분석 시작

2주차부터는 본격적으로 데이터 분석에 들어갔습니다.

- pandas 기초, CSV·엑셀·JSON 데이터 입출력
- matplotlib·seaborn 시각화 (선 그래프, 막대, 히스토그램, 산점도, 박스플롯, 히트맵 등)
- 결측치 처리, 데이터 전처리
- 기상청 공공데이터 분석, 인구 피라미드 그리기, 지도 시각화
- groupby, pivot_table, merge, concat 같은 데이터프레임 응용

수업 시간에 그린 그래프만 20개가 넘는데, 똑같은 데이터라도 어떤 그래프를 고르느냐에 따라 전달되는 메시지가 완전히 달라진다는 걸 체감했어요.

## 5. 미니 프로젝트 - 나의 입출금 시스템 (가계부 분석)

배운 pandas 기능을 한 번에 써보기 위해 **통장 거래 내역을 분석하는 프로젝트**를 진행했습니다. 1~3월 거래 내역을 데이터프레임으로 만들고 아래 질문에 답하는 것이 목표였어요.

1. 총 수입 · 지출 · 남은 금액은 얼마인가?
2. 어떤 항목에 가장 많이 썼는가?
3. 월별로 얼마씩 남았는가?

마스크 필터링으로 수입·지출을 나누고, `apply`로 10만 원 이상 지출에 '큰 지출' 표시를 붙이고, `groupby`로 항목별 순위를, `pivot_table`로 월별 요약표를 만들었습니다. 결과는 그래프 이미지와 CSV 파일로 저장했어요.

분석해 보니 3개월 동안 수입 600만 원 중 371만 원을 지출했고, 지출 1위는 역시 월세(180만 원)였습니다. 😅

이어서 실제 가계부 앱의 데이터 처리 부분처럼, 사용자가 올린 데이터를 **검증**하는 단계도 연습했습니다. 날짜 형식이 맞는지, 구분이 '수입/지출'인지, 금액이 정상 범위인지 검사하는 함수를 만들면서, 금융 데이터에서는 "분석"만큼 "데이터를 믿을 수 있게 만드는 것"이 중요하다는 걸 배웠어요.

[📷 이미지 4 : 항목별 지출 그래프 / 월별 요약 그래프 (img/입출금 폴더)]

### 프로젝트하면서 헷갈렸던 것들

직접 부딪히며 배운 것들이라 오래 기억에 남을 것 같아요.

- 날짜는 처음엔 문자열이라 `pd.to_datetime()`으로 바꿔야 월을 꺼낼 수 있다
- 필터링한 데이터에 열을 추가할 땐 `.copy()`를 붙여야 경고가 안 난다
- `savefig()`는 `show()`보다 먼저! 반대로 하면 빈 그림이 저장된다
- 엑셀에서 열 CSV는 `encoding='utf-8-sig'`로 저장해야 한글이 안 깨진다
- `merge`의 기본값은 inner join이라 한쪽에만 있는 데이터는 사라진다
