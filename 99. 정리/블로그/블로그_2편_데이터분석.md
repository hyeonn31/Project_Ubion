## 1. pandas 기초 : 엑셀 같은 표를 코드로 다루기

데이터 분석의 시작은 **pandas**였습니다. pandas는 엑셀처럼 행과 열로 된 표(데이터프레임)를 파이썬 코드로 다룰 수 있게 해주는 라이브러리예요.

처음에는 시리즈(Series)와 데이터프레임(DataFrame)의 차이, 행과 열을 고르는 `loc`과 `iloc`의 차이부터 배웠습니다. 그다음엔 **데이터 입출력**을 배웠는데, CSV·엑셀·JSON·HTML 파일을 읽고 저장하는 실습을 했어요. 주가 데이터 엑셀 파일, 서울 지역 대학교 위치 데이터 같은 실제 데이터를 불러와 보니 "아, 이게 진짜 데이터 분석이구나" 하는 느낌이 들었습니다.

엑셀로 하면 마우스로 수십 번 클릭해야 하는 작업을 코드 몇 줄로 끝낼 수 있고, 같은 작업을 다른 파일에 그대로 반복할 수 있다는 게 가장 큰 장점이라고 느꼈어요.

## 2. 시각화 : 같은 데이터, 다른 이야기

시각화 수업에서는 matplotlib과 seaborn으로 정말 다양한 그래프를 그려 봤습니다. 실습 결과를 이미지로 저장해 두었는데 세어 보니 20개가 넘더라고요.

- 선 그래프, 면적 그래프, 막대 그래프, 가로 막대 그래프
- 히스토그램, 산점도, 버블 차트, 파이 차트
- 박스플롯, 바이올린 플롯, 회귀선 그래프, 히트맵
- 그래프에 주석(annotate) 달기, 여러 그래프를 한 화면에 그리기(subplots)

똑같은 데이터라도 어떤 그래프를 고르느냐에 따라 전달되는 메시지가 완전히 달라진다는 걸 체감했어요. 추세를 보여줄 땐 선 그래프, 항목끼리 비교할 땐 막대 그래프, 분포를 볼 땐 히스토그램이나 박스플롯처럼요.

그리고 한글이 네모(□)로 깨지는 문제를 처음 만났는데, 한글 글꼴을 따로 지정해야 한다는 것도 이때 배웠습니다. 데이터 분석하시는 분들이라면 다 한 번씩 겪는 일이라고 하더라고요. 😅

## 3. 데이터 전처리 : 분석의 80%는 데이터 정리

"데이터 분석가는 시간의 80%를 데이터 정리에 쓴다"는 말을 들었는데, 전처리 수업을 듣고 나서 그 말이 이해됐어요.

- **누락 데이터(NaN) 처리** : 비어 있는 값을 찾아서 지우거나 다른 값으로 채우기
- **중복 데이터 제거**
- **데이터 표준화** : 단위 환산, 자료형 변환
- **범주형 데이터 처리** : 연속된 숫자를 구간으로 나눠 카테고리로 만들기
- **정규화와 피처 스케일링** : 값의 크기가 서로 다른 열들을 비슷한 범위로 맞추기
- **시계열 데이터** : 문자열 날짜를 날짜형으로 바꾸고 활용하기

누락 데이터가 많으면 데이터 품질이 떨어지고 분석 결과나 AI 모델이 왜곡될 수 있다는 설명이 인상 깊었어요. 금융 데이터는 숫자 하나가 틀려도 큰 문제가 되기 때문에, 분석 전에 데이터를 꼼꼼히 정리하는 습관이 꼭 필요하겠다고 느꼈습니다.

## 4. 공공데이터로 인구 피라미드 그리기

실제 공공데이터를 활용한 실습도 했습니다. 기상청 데이터를 다뤄 보고, 연령별 인구 데이터로 **인구 피라미드**를 그려 봤어요.

처음에는 남녀 막대를 그냥 겹쳐 그렸더니 알아보기 힘들었는데, 한쪽을 음수로 바꿔서 좌우로 펼치고, 색과 축 눈금을 다듬어서 보기 좋은 피라미드로 완성했습니다. 같은 데이터인데 조금만 손보니까 훨씬 읽기 쉬워지는 걸 보면서 "보는 사람을 생각하는 시각화"가 뭔지 알게 됐어요.

지도 시각화도 해봤는데, 서울 지역 대학교 위치를 지도 위에 표시하니 표로 볼 때보다 훨씬 직관적이었습니다.

## 5. 데이터프레임 응용 : apply, groupby, pivot, merge

2주차 마지막에는 데이터프레임을 자유롭게 다루는 응용 기술을 배웠습니다.

- **apply** : 열의 모든 값에 함수를 한 번에 적용하기
- **필터링** : 조건에 맞는 행만 골라내기 (불린 인덱싱, isin)
- **concat / merge / join** : 여러 표를 이어 붙이거나 key 기준으로 합치기
- **groupby** : 그룹별로 합계·평균 구하기
- **pivot_table** : 행·열·값·집계 함수를 정해서 요약표 만들기

타이타닉 데이터로 객실 등급별 생존율을 피벗 테이블로 만들어 보는 실습이 특히 재미있었어요. 엑셀의 피벗 테이블 기능을 코드 한 줄로 할 수 있다는 게 신기했습니다. 그리고 이렇게 배운 기능들은 다음 편에서 소개할 **가계부 분석 프로젝트**에 그대로 쓰였어요.
