# 07.stock-chart2.py 코드 설명

## 0. 핵심 개념: Streamlit은 "위에서 아래로 매번 다시 실행"된다

- 사용자가 날짜를 바꾸거나 종목코드를 입력할 때마다 **파일 전체가 처음부터 끝까지 다시 실행**된다.
- `st.date_input()`, `st.text_input()` 같은 입력 위젯은 **화면에 칸을 그리는 동시에, 지금 입력돼 있는 값을 돌려준다.**

예: `code = st.text_input(...)` → "입력칸을 그리고, 거기 적힌 글자를 `code`에 담아라."
사용자가 `000660`으로 바꾸면 파일이 다시 실행되고, 이번엔 `code`에 `"000660"`이 담긴다.
이벤트 처리 코드 없이 그냥 위에서 아래로 읽으면 되는 구조다.

---

## 1. 준비

```python
import streamlit as st
import FinanceDataReader as fdr
import datetime

st.title('종목차트검색')
```

- **streamlit**: 웹 화면을 만드는 도구
- **FinanceDataReader**: 주가·환율·지수 데이터를 가져오는 도구
- **datetime**: 날짜를 다루는 도구
- `st.title()`: 페이지 맨 위에 큰 제목을 쓴다.

## 2. 사이드바: 입력받기

```python
with st.sidebar:
    date = st.date_input("조회 시작일을 선택해 주세요", datetime.datetime(2025,8,27))
    code = st.text_input("종목코드", value="005930")
```

- `with st.sidebar:` 아래에 **들여쓴 것만** 왼쪽 사이드바에 그려진다.
  → **들여쓰기가 "어디에 그릴지"를 정한다.** (처음 코드에서 차트가 사이드바 안에 들어갔던 이유)
- `date`에는 달력에서 고른 날짜, `code`에는 입력한 종목코드 문자열이 담긴다.
- 두 번째 인자(`2025-08-27`, `"005930"`)는 처음 화면에 보일 **기본값**이다.

## 3. 입력이 있을 때만 실행

```python
if code and date:
```

- 빈 문자열(`""`)은 파이썬에서 **거짓**으로 판단된다.
- 종목코드 칸을 지우면 아래 코드는 통째로 건너뛴다. → 빈 코드로 데이터를 요청하다 에러가 나는 것을 막는다.

## 4. 데이터 가져오기

```python
    df = fdr.DataReader(code, date)
    data = df.sort_index(ascending=True).loc[:,'Close']
```

- `fdr.DataReader(종목, 시작일)`: 그 날짜부터 오늘까지의 주가를 **표(DataFrame)** 로 가져온다.

  | Date (인덱스) | Open | High | Low | Close | Volume | Change |
  |---|---|---|---|---|---|---|
  | 2025-08-27 | 70,000 | 70,500 | 69,800 | 70,200 | 1,234,567 | 0.003 |
  | ... | | | | | | |

  날짜는 일반 열이 아니라 **인덱스**(각 행의 이름표)다.

- 두 번째 줄 풀이:

  | 부분 | 의미 |
  |---|---|
  | `df.sort_index(ascending=True)` | 인덱스(날짜) 기준 **오름차순** 정렬 (과거 → 최근) |
  | `.loc[:, 'Close']` | `loc[행, 열]` 형태. `:` = 모든 행, 열은 `'Close'`만 |
  | `data = ...` | 결과를 `data`에 저장 |

  `df['Close']`와 결과는 같고, 정렬은 혹시 모를 상황을 대비한 안전장치다.

## 5. 탭으로 나눠서 보여주기

```python
    tab1, tab2 = st.tabs(['차트','데이터'])

    with tab1:
        st.line_chart(data)

    with tab2:
        st.dataframe(df.sort_index(ascending=False))
```

- `st.tabs([...])`: 탭 버튼을 만들고 각 탭의 "그릴 공간"을 돌려준다. 이름이 두 개니까 두 변수로 나눠 받는다.
- `with tab1:` 아래는 차트 탭에 그려진다. (사이드바와 같은 원리)
- `st.line_chart(data)`: 인덱스(날짜)를 **x축**, 값(종가)을 **y축**으로 선 그래프를 자동으로 그린다.
- `st.dataframe(...)`: 표를 보여준다. `ascending=False`라서 **최신 날짜가 맨 위**에 온다.

## 6. 접었다 펴는 설명 상자

```python
    with st.expander('컬럼설명'):
        st.markdown('''
        - Open : 시가
        ...
        ''')
```

- `st.expander`: 클릭하면 펼쳐지는 상자
- `st.markdown`: 마크다운 문법으로 글을 쓴다. `-`로 시작하는 줄은 글머리 기호 목록이 된다.
- `'''`(따옴표 세 개): 여러 줄짜리 문자열

## 전체 흐름

```
사용자가 입력을 바꿈
   ↓
파일 전체 다시 실행
   ↓
사이드바에서 date, code 값 받기
   ↓
값이 있으면 → 데이터 가져오기 → 종가만 뽑기
   ↓
탭1: 그래프 / 탭2: 표 / 설명 상자
```

## 직접 해보기

1. `value="005930"` → `"000660"`(SK하이닉스)으로 바꿔서 실행해보기
2. `st.line_chart(data)` → `st.line_chart(df[['Open','Close']])`로 바꾸기 (시가·종가 두 선)
3. `st.dataframe(...)` 줄의 들여쓰기를 지워 `with tab2:` 밖으로 빼보기 → 표가 어디로 가는지 확인
