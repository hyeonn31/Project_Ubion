## 1. 누락 데이터 처리

### NaN 이란?

**NaN = Not a Number** = "여기 값이 없음" 표시. pandas 에서는 `numpy.nan` (줄여서 `np.nan`) 으로 나타낸다.

- 설문 응답 안 함, 측정 실패, 기록 누락 등으로 생긴다
- 누락 데이터가 많으면 **데이터 품질이 떨어지고, AI 알고리즘이 왜곡**된다
- NaN 은 계산에 끼면 결과도 NaN 이 된다 (`NaN + 10 = NaN`)

### 처리 전략 3가지

| 전략 | 방법 | 언제 |
|---|---|---|
| **확인** | 어디에 몇 개 있나 세기 | 항상 제일 먼저 |
| **삭제** | NaN 이 있는 행/열 지우기 | NaN 이 너무 많은 열, 또는 NaN 행이 아주 적을 때 |
| **치환(채우기)** | 평균, 중앙값, 최빈값 등으로 채우기 | 데이터를 버리기 아까울 때 |

### 1-1. 누락 데이터 확인

#### `value_counts(dropna=False)` : 값별 개수 + NaN 개수

```python
import seaborn as sns

# seaborn 내장 타이타닉 데이터셋 불러오기 (891행 x 15열)
df = sns.load_dataset('titanic')

# dropna=False : NaN 값까지 집계
nan_deck = df['deck'].value_counts(dropna=False)
print(nan_deck)
```

```
deck
NaN    688
C       59
B       47
D       33
E       32
A       15
F       13
G        4
Name: count, dtype: int64
```

→ `deck`(객실 갑판) 열은 891개 중 **688개가 NaN** (77%!)

> `value_counts()` 는 기본값이 `dropna=True` 라서 **NaN 을 빼고** 센다. NaN 개수도 보려면 꼭 `dropna=False`.

#### `isnull()` / `notnull()` : 칸마다 NaN 인지 True/False

```python
# isnull() : 누락 데이터면 True, 유효한 데이터가 존재하면 False
print(df.head().isnull())      # head() : 앞 5행만 확인
```

```
   survived  pclass    sex    age  ...   deck  embark_town  alive  alone
0     False   False  False  False  ...   True        False  False  False
1     False   False  False  False  ...  False        False  False  False
2     False   False  False  False  ...   True        False  False  False
3     False   False  False  False  ...  False        False  False  False
4     False   False  False  False  ...   True        False  False  False
```

```python
# notnull() : isnull() 의 반대. 유효한 데이터면 True, 누락 데이터면 False
print(df.head().notnull())
```

| 메서드 | NaN 이면 | 값이 있으면 |
|---|---|---|
| `isnull()` (= `isna()`) | **True** | False |
| `notnull()` (= `notna()`) | False | **True** |

#### `isnull().sum()` : 열별 NaN 개수 (가장 많이 쓰는 방법!)

```python
# True = 1, False = 0 으로 계산되므로 sum()하면 NaN 개수가 됨
# axis=0 : 행 방향(위->아래)으로 더함 -> 열별 NaN 개수
print(df.head().isnull().sum(axis=0))     # 앞 5행만
df.isnull().sum(axis=0)                   # 전체 데이터
```

```
survived         0
pclass           0
sex              0
age            177      ← 나이 모르는 승객 177명
sibsp            0
parch            0
fare             0
embarked         2
class            0
who              0
adult_male       0
deck           688      ← 갑판 정보 없는 승객 688명
embark_town      2
alive            0
alone            0
dtype: int64
```

> 💡 **왜 sum() 하면 개수가 되나?** 파이썬에서 `True = 1`, `False = 0` 이다.
> True(NaN) 를 다 더하면 = NaN 의 개수.
>
> 비율로 보고 싶으면 `df.isnull().mean()` → `deck` 은 0.772 (77.2%)

#### for 문으로 직접 세기 (원리 이해용)

```python
import seaborn as sns

df = sns.load_dataset('titanic')
missing_df = df.isnull()        # 전체 데이터를 True(NaN) / False 로 변환

# 열마다 NaN(True) 개수 출력
for col in missing_df.columns:
    missing_count = missing_df[col].value_counts()    # True, False 각각의 개수

    try:
        print(col, ': ', missing_count[True])   # NaN 값이 있으면 개수를 출력
    except:
        print(col, ': ', 0)                     # True 가 없으면 KeyError → 0개 출력
```

```
survived :  0
pclass :  0
sex :  0
age :  177
...
deck :  688
embark_town :  2
```

- `missing_df[col].value_counts()` → 그 열에 True 가 몇 개, False 가 몇 개인지
- NaN 이 하나도 없는 열은 결과에 **True 자체가 없어서** `missing_count[True]` 가 `KeyError` → `except` 로 0 출력
- 결과는 `df.isnull().sum()` 과 같다 → **실무에서는 한 줄짜리 `isnull().sum()` 을 쓴다**

### 1-2. 누락 데이터 삭제 : `dropna()`

#### `dropna()` 주요 옵션

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `axis=0` | NaN 이 있는 **행**을 삭제 | ⭕ 기본 |
| `axis=1` | NaN 이 있는 **열**을 삭제 | |
| `how='any'` | NaN 이 **하나라도** 있으면 삭제 | ⭕ 기본 |
| `how='all'` | **전부** NaN 일 때만 삭제 | |
| `thresh=N` | NaN 이 아닌 값이 **N개 이상**이어야 남김 | |
| `subset=['열']` | NaN 을 **검사할 열**을 지정 | |
| `inplace=True` | 원본 df 를 직접 수정 (반환값 없음) | False |

#### 열 삭제 : `thresh` 로 NaN 이 너무 많은 열 지우기

```python
# NaN이 아닌 값이 500개 이상인 열만 남김 - deck 열(891개 중 688개의 NaN 값)
# axis=1 : 열 단위로 삭제, thresh=500 : 유효한 값이 500개 미만인 열은 삭제
df_thresh = df.dropna(axis=1, thresh=500)
print(df_thresh.columns)        # deck 열이 삭제된 것 확인
```

```
Index(['survived', 'pclass', 'sex', 'age', 'sibsp', 'parch', 'fare',
       'embarked', 'class', 'who', 'adult_male', 'embark_town', 'alive',
       'alone'],
      dtype='str')
```

→ `deck` 은 유효한 값이 891 - 688 = **203개** < 500 이라서 삭제. 15열 → **14열**

> 💡 `thresh` 는 "NaN 개수" 가 아니라 **"NaN 아닌 값의 개수"** 기준이다. 헷갈리기 쉬움!
> `age` 는 유효한 값이 891 - 177 = 714개 ≥ 500 이라서 살아남았다.

#### 같은 결과를 마스크(조건)로 : `loc`

```python
# NaN이 500개 이하인 열만 남기기
# df.isnull().sum() <= 500 : 열별로 True/False 를 가진 시리즈(mask)
# df.loc[:, mask] : 모든 행, mask가 True인 열만 선택
df.loc[:, df.isnull().sum() <= 500]
```

| 방법 | 기준 |
|---|---|
| `dropna(axis=1, thresh=500)` | **유효한 값**이 500개 이상인 열 남김 |
| `loc[:, df.isnull().sum() <= 500]` | **NaN** 이 500개 이하인 열 남김 |

→ 이 데이터에서는 둘 다 `deck` 만 빠진다. (기준이 다르니 데이터에 따라 결과가 다를 수 있음)

#### 행 삭제 : `subset` 으로 특정 열 기준

```python
# age 열에 나이 데이터가 없는 모든 행을 삭제 - age 열(891개 중 177개의 NaN 값)
# subset=['age'] : NaN을 검사할 열 지정
# how='any' : 지정한 열 중 하나라도 NaN이면 행 삭제 / how='all' : 모두 NaN일 경우에만 삭제
# axis=0 : 행 단위로 삭제
df_age = df.dropna(subset=['age'], how='any', axis=0)
df_age.head()
```

→ 891행 → **714행** (age 가 NaN 인 177행 삭제)

```
   survived  pclass     sex   age  ...  deck  embark_town alive  alone
0         0       3    male  22.0  ...   NaN  Southampton    no  False
1         1       1  female  38.0  ...     C    Cherbourg   yes  False
...
```

→ `deck` 은 여전히 NaN 이 남아 있다. `subset=['age']` 라서 **age 만 검사**했기 때문.

#### ⚠️ subset 없이 그냥 `dropna()` 하면?

```python
df.dropna().shape      # (182, 15)
```

→ **모든 열**을 검사해서 NaN 이 하나라도 있으면 지운다. `deck` 때문에 891행 중 **182행만** 남는다!
데이터가 확 줄어드니 **항상 `subset` 을 지정하거나, NaN 많은 열을 먼저 지우는 게 좋다.**

### 1-3. 누락 데이터 치환 : `fillna()`

데이터를 버리기 아까울 때는 **그럴듯한 값으로 채운다.**

#### 숫자 열 → 평균으로 채우기

```python
import seaborn as sns

df = sns.load_dataset('titanic')
print(df['age'].head(10))       # 5번 행이 NaN인 것 확인
```

```
0    22.0
1    38.0
2    26.0
3    35.0
4    35.0
5     NaN      ← 나이 모름
6    54.0
7     2.0
8    27.0
9    14.0
Name: age, dtype: float64
```

```python
# age 열의 NaN값을 다른 나이 데이터의 평균으로 변경
mean_age = df['age'].mean(axis=0)       # age 열의 평균 계산 (NaN 값은 자동으로 빼고 계산)
df['age'] = df['age'].fillna(mean_age)  # NaN 자리를 평균값으로 채움

print(df['age'].head(10))
```

```
0    22.000000
1    38.000000
2    26.000000
3    35.000000
4    35.000000
5    29.699118      ← 평균값으로 채워짐
6    54.000000
...
```

> 💡 `mean()`, `median()`, `sum()` 같은 pandas 계산 함수는 **NaN 을 자동으로 건너뛰고** 계산한다.
> `fillna()` 는 원본을 바꾸지 않고 **새 결과를 반환**하므로 `df['age'] = ...` 처럼 다시 넣어 줘야 한다.

#### 평균 vs 중앙값 : 언제 뭘 쓰나?

```python
df['age'].median()     # 중앙값 : 28.0  (평균은 29.7)
```

| 데이터 성격 | 추천 | 이유 |
|---|---|---|
| 대칭적인 분포 | **평균** | 평균이 데이터의 가운데를 잘 대표함 |
| 이상치(튀는 값)가 많은 데이터 | **중앙값** | 평균은 튀는 값에 끌려감 |
| 소득, 부동산 가격 | **중앙값** | 한쪽으로 치우친 분포 (소수의 부자가 평균을 끌어올림) |
| 센서 측정값 | **평균** | 오차가 대칭적이고 이상치가 적음 |
| 금융 거래 금액 | **중앙값** | 큰 거래 몇 건이 평균을 왜곡할 수 있음 |

> 💡 예) 직원 연봉 3천, 3천, 3천, 3천, **10억** → 평균 2억 2400만 (아무도 이렇게 안 받음), 중앙값 3천 (현실적)

#### 글자 열 → 최빈값(가장 많이 나온 값)으로 채우기

글자는 평균을 낼 수 없으니 **가장 흔한 값**으로 채운다.

```python
import seaborn as sns

df = sns.load_dataset('titanic')
print(df['embark_town'][825:830])       # 829번 행이 NaN인 것 확인
```

```
825     Queenstown
826    Southampton
827      Cherbourg
828     Queenstown
829            NaN
Name: embark_town, dtype: str
```

```python
# embark_town 열의 NaN값을 승선도시 중에서 가장 많이 출현한 값(최빈값)으로 치환하기
# value_counts() : 값별 개수 (많은 순 정렬), idxmax() : 개수가 가장 큰 값의 인덱스(도시 이름)
most_freq = df['embark_town'].value_counts(dropna=True).idxmax()
print(most_freq)
```

```
Southampton
```

**어떻게 찾았나?** `value_counts()` 결과를 보면

```
embark_town
Southampton    644    ← 가장 많음 → idxmax() 가 이 "이름"을 돌려줌
Cherbourg      168
Queenstown      77
```

| 함수 | 돌려주는 것 | 결과 |
|---|---|---|
| `max()` | 가장 큰 **값** | 644 |
| `idxmax()` | 가장 큰 값의 **인덱스(이름표)** | `'Southampton'` |

```python
# NaN 자리를 최빈값(Southampton)으로 채움
df['embark_town'] = df['embark_town'].fillna(most_freq)

print(df['embark_town'][825:830])
```

```
825     Queenstown
826    Southampton
827      Cherbourg
828     Queenstown
829    Southampton      ← 채워짐
Name: embark_town, dtype: str
```

> 💡 같은 결과를 더 짧게 : `df['embark_town'].mode()[0]` (`mode()` = 최빈값)

#### 다른 채우기 방법들 (참고)

```python
s = pd.Series([1, np.nan, 3, np.nan, 5])

s.fillna(0)     # [1, 0, 3, 0, 5]   ← 정해진 값으로
s.ffill()       # [1, 1, 3, 3, 5]   ← 바로 앞 값으로 (forward fill)
s.bfill()       # [1, 3, 3, 5, 5]   ← 바로 뒤 값으로 (backward fill)
```

→ `ffill`/`bfill` 은 **주가, 기온처럼 시간 순서가 있는 데이터**에서 자주 쓴다. (어제 값으로 오늘 빈칸 채우기)

### 채우기 방법 비교

| 방법 | 코드 | 이럴 때 |
|---|---|---|
| 평균 | `fillna(df['열'].mean())` | 숫자, 대칭 분포 |
| 중앙값 | `fillna(df['열'].median())` | 숫자, 이상치 많음 |
| 최빈값 | `fillna(df['열'].value_counts().idxmax())` | 글자(범주형) |
| 고정값 | `fillna(0)`, `fillna('Unknown')` | "없음" 자체가 의미 있을 때 |
| 앞/뒤 값 | `ffill()`, `bfill()` | 시계열 데이터 |

## 2. 중복 데이터 제거

같은 데이터가 두 번 들어가면 **그 데이터의 영향이 두 배**가 되어 분석이 왜곡된다.

```python
import pandas as pd

# 중복 데이터가 있는 데이터프레임 생성 (0행과 1행이 완전히 같음)
df = pd.DataFrame({'c1': ['a', 'a', 'b', 'a', 'b'],
                   'c2': [1, 1, 1, 2, 2],
                   'c3': [1, 1, 2, 2, 2]})
print(df)
```

```
  c1  c2  c3
0  a   1   1
1  a   1   1      ← 0행과 완전히 같음
2  b   1   2
3  a   2   2
4  b   2   2
```

### 중복 확인 : `duplicated()`

```python
df.duplicated()          # [False, True, False, False, False]
df.duplicated().sum()    # 1  ← 중복 행 개수
```

- **앞에서 이미 나온 행과 같으면 True**
- 처음 나온 행(0행)은 False, 두 번째로 나온 행(1행)이 True

### 중복 행 제거 : `drop_duplicates()`

```python
# 데이터프레임에서 중복 행을 제거
# 모든 열의 값이 같은 행을 찾아 처음 나온 행만 남기고 삭제 (1행 삭제)
df2 = df.drop_duplicates()
print(df2)
```

```
  c1  c2  c3
0  a   1   1
2  b   1   2
3  a   2   2
4  b   2   2
```

→ 1행 삭제. **인덱스 번호는 그대로**라서 0, 2, 3, 4 로 건너뛴다. (다시 0부터 매기려면 `reset_index(drop=True)`)

### 특정 열 기준으로 중복 제거 : `subset`

```python
# c2, c3열을 기준으로 중복 행을 제거
# c2, c3 값만 같으면 중복으로 판단 (1행, 4행 삭제)
df3 = df.drop_duplicates(subset=['c2', 'c3'])
print(df3)
```

```
  c1  c2  c3
0  a   1   1
2  b   1   2
3  a   2   2
```

**왜 4행이 지워졌나?** `c1` 은 무시하고 `c2, c3` 만 본다.

| 행 | (c2, c3) | 판단 |
|---|---|---|
| 0 | (1, 1) | 처음 → 남김 |
| 1 | (1, 1) | 0행과 같음 → **삭제** |
| 2 | (1, 2) | 처음 → 남김 |
| 3 | (2, 2) | 처음 → 남김 |
| 4 | (2, 2) | 3행과 같음 → **삭제** (c1 은 b 로 다르지만 무시) |

### `keep` 옵션 : 어느 쪽을 남길까

| 옵션 | 뜻 |
|---|---|
| `keep='first'` (기본) | 처음 나온 행을 남김 |
| `keep='last'` | 마지막에 나온 행을 남김 |
| `keep=False` | 중복된 행은 **전부** 삭제 |

```python
df.drop_duplicates(keep='last')     # 0행이 지워지고 1행이 남음
```

### 3-1. 단위 환산

**측정 단위를 동일하게 맞추기.** 마일, 야드, 온스(영미권) → 미터, 평, 그램(한국)

| 단위 | 뜻 | 환산 |
|---|---|---|
| mpg | mile per gallon, 갤런당 마일 | |
| kpl | km per liter, 리터당 킬로미터 (km/L) | 한국에서 쓰는 연비 단위 |
| 1 마일 | | = 1.60934 km |
| 1 갤런 | | = 3.78541 L |
| 1 mpg | | = 1.60934 / 3.78541 ≈ **0.425 km/L** |

```python
# mpg -> kpl 환산 계수 (1마일 km / 1갤런 L)
mpg_to_kpl = 1.60934 / 3.78541
df["kpl"] = df["mpg"] * mpg_to_kpl      # 새 열 kpl 추가
print(df.head(3))
```

```
    mpg  ...       kpl
0  18.0  ...  7.652571
1  15.0  ...  6.377143
2  18.0  ...  7.652571
```

**계산 원리** : 18 mpg = 1갤런으로 18마일 = 3.78541L 로 28.97km → 1L 당 **7.65km**

```python
# kpl 열을 소수점 둘째 자리까지 반올림
df["kpl"] = df["kpl"].round(2)
print(df.head(3))
```

```
    mpg  ...   kpl
0  18.0  ...  7.65
1  15.0  ...  6.38
2  18.0  ...  7.65
```

> 💡 **열 전체에 한 번에 계산** : `df["mpg"] * 0.425` 처럼 쓰면 for 문 없이 **모든 행**이 계산된다.
> 새 열 이름에 대입하면(`df["kpl"] = ...`) 열이 자동으로 추가된다.

### 3-2. 자료형 변환

#### 문제 발견 : 숫자여야 할 열이 문자열

```python
import numpy as np
import pandas as pd

df = pd.read_csv("./data/auto-mpg.csv", header=None)
df.columns = [...]   # 위와 같음

# 열별 자료형 확인
print(df.dtypes)
```

```
mpg             float64
cylinders         int64
displacement    float64
horsepower          str      ← ?! 마력은 숫자인데 문자열
weight          float64

```

#### 원인 찾기 : `unique()` 로 고유값 확인

```python
# horsepower 열의 고유값 확인
print(df['horsepower'].unique())
```

```
['130.0', '165.0', '150.0', '140.0', '198.0', ..., '193.0', '?', '100.0', ...]
```

→ 중간에 **`'?'`** 가 섞여 있다! 열에 글자가 하나라도 있으면 pandas 는 **열 전체를 문자열로** 읽는다.
(`'130.0'` 은 숫자 130 이 아니라 글자 "1", "3", "0", ".", "0")

| 자료형 | 뜻 | 예 |
|---|---|---|
| `int64` | 정수 | 8, 70 |
| `float64` | 실수 (소수점) | 18.0, 3504.0 |
| `str` / `object` | 문자열 | `'chevrolet'`, `'130.0'` |
| `category` | 범주형 | `'USA'`, `'EU'`, `'JAPAN'` |
| `datetime64` | 날짜/시간 | 2018-07-02 |

#### 해결 : `'?'` → NaN → 삭제 → 숫자로 변환

```python
# 누락 데이터('?') 삭제
df['horsepower'] = df['horsepower'].replace('?', np.nan)    # 1. '?'을 np.nan으로 변경
df.dropna(subset=['horsepower'], axis=0, inplace=True)      # 2. 누락데이터 행을 삭제
df['horsepower'] = df['horsepower'].astype('float')         # 3. 문자열을 실수형으로 변환

print(df['horsepower'].dtypes)
```

```
float64
```

| 단계 | 코드 | 왜? |
|---|---|---|
| 1 | `replace('?', np.nan)` | `'?'` 는 pandas 가 NaN 으로 모른다 → 진짜 NaN 으로 바꿔야 `dropna` 가 알아봄 |
| 2 | `dropna(subset=[...])` | NaN 행 삭제 (398행 → 392행) |
| 3 | `astype('float')` | 이제 전부 숫자 모양 글자라서 실수로 변환 가능 |

> ⚠️ 순서가 중요! `'?'` 가 남아 있는 상태에서 `astype('float')` 하면
> `ValueError: could not convert string to float: '?'` 에러
>
> ⚠️ `np.nan` 을 쓰려면 `import numpy as np` 필수 (없으면 `NameError: name 'np' is not defined`)

> 💡 **한 줄로 끝내는 방법** : `pd.to_numeric(df['horsepower'], errors='coerce')`
> 숫자로 바꿀 수 없는 값(`'?'`)은 자동으로 NaN 이 된다. → `['1', '?', '3']` → `[1.0, NaN, 3.0]`

#### 숫자 코드 → 의미 있는 이름 : `replace({딕셔너리})`

```python
# origin 열의 고유값 확인 : 카테고리컬 데이터
# 1:'USA', 2:'EU', 3:'JAPAN'
print(df['origin'].unique())

# 딕셔너리 {기존값: 새 값} 으로 숫자를 국가 이름으로 바꿈
df['origin'] = df['origin'].replace({1: 'USA', 2: 'EU', 3: 'JAPAN'})

```

```

```

→ 1, 2, 3 은 크기 의미가 없는 **나라 코드**라서 이름으로 바꾸면 읽기 쉽다.

#### 문자열 → 범주형 : `astype('category')`

```python
# origin 열의 문자열 자료형을 범주형으로 변환
df['origin'] = df['origin'].astype('category')
print(df['origin'].dtypes)
```

**범주형(category) 으로 바꾸는 이유**

1. **메모리 절약** : `'USA'` 글자를 수백 번 저장하는 대신, 종류 목록 + 번호만 저장
   - 예) `['USA','JAPAN','EU','USA']` x 100 = 문자열 **21,032 바이트** → category **689 바이트** (약 30배 절약)
2. **"정해진 종류 중 하나" 라는 의미**가 명확해진다

#### 숫자 → 범주형 : `model year`

```python
# model year 열의 정수형을 범주형으로 변환
```

## 4. 범주형(카테고리) 데이터 처리

### 4-1. 구간 분할 (binning)

**연속된 숫자를 일정 구간으로 나누고, 범주형(카테고리) 데이터로 바꾸는 것.**

```
마력 46 ~ 230 (연속된 숫자)  →  저출력 / 보통출력 / 고출력 (3개 범주)
```

> 💡 예) 나이 → 10대 / 20대 / 30대, 시험 점수 → A / B / C / D / F

#### 준비 : horsepower 를 숫자로

```python
import numpy as np
import pandas as pd

df = pd.read_csv("./data/auto-mpg.csv", header=None)
df.columns = [...]   # 위와 같음

# 누락 데이터('?') 삭제
df['horsepower'] = df['horsepower'].replace('?', np.nan)
df.dropna(subset=['horsepower'], axis=0, inplace=True)
df['horsepower'] = df['horsepower'].astype('float')
```

#### 1단계 : 경계값 구하기 : `np.histogram()`

```python
# np.histogram 함수로 3개의 bin으로 나누는 경계 값의 리스트 구하기
# count : 각 구간의 데이터 개수, bin_dividers : 구간 경계값(4개)
# bins=3 : 최소값~최대값을 같은 간격으로 3등분

count, bin_dividers = np.histogram(df['horsepower'], bins=3)
print(bin_dividers)
print(count)
```

```
[ 46.         107.33333333 168.66666667 230.        ]
[257 103  32]
```

**계산 원리** : 최소 46 ~ 최대 230 → 범위 184 → 3등분 하면 한 칸에 **61.33**

| 구간 | 범위 | 개수 |
|---|---|---|
| 1구간 | 46 ≤ horsepower < 107.33 | 257대 |
| 2구간 | 107.33 ≤ horsepower < 168.67 | 103대 |
| 3구간 | 168.67 ≤ horsepower ≤ 230 | 32대 |

- **bin** = 구간(통). 데이터를 나눠 담는 상자
- 3개 구간을 만들려면 **경계값은 4개** 필요 (칸막이 4개 → 칸 3개)
- `np.histogram` 은 두 개를 돌려준다 → `count, bin_dividers = ...` 로 나눠 받기

#### 2단계 : 구간 나누고 이름 붙이기 : `pd.cut()`

```python
# 3개의 bin에 이름 지정
bin_names = ['저출력', '보통출력', '고출력']

# pd.cut() : 연속된 숫자 데이터를 구간별 범주로 나눔
df['hp_bin'] = pd.cut(x=df['horsepower'],      # 나눌 데이터
                      bins=bin_dividers,       # 경계 값 리스트 (4개)
                      labels=bin_names,        # 각 구간 이름 (3개)
                      include_lowest=True)     # 첫 경계값(46.0)도 1구간에 포함

print(df[['horsepower', 'hp_bin']].head(15))
```

```
    horsepower hp_bin
0        130.0   보통출력
1        165.0   보통출력
2        150.0   보통출력
3        150.0   보통출력
4        140.0   보통출력
5        198.0    고출력
6        220.0    고출력
...
14        95.0    저출력
```

| 옵션 | 뜻 |
|---|---|
| `x` | 나눌 데이터 (시리즈) |
| `bins` | 경계값 리스트. **경계값 개수 = 구간 개수 + 1** |
| `labels` | 구간 이름. **개수 = 구간 개수** (안 맞으면 에러) |
| `include_lowest=True` | 맨 처음 경계값을 첫 구간에 포함 |

#### `include_lowest=True` 가 왜 필요한가?

`pd.cut` 은 기본적으로 구간을 **`(왼쪽, 오른쪽]`** = 왼쪽 미포함, 오른쪽 포함으로 만든다.

```
(46, 107.33]   ← 46 은 "초과" 라서 포함 안 됨!
```

→ 최소값 **46 마력** 자동차는 어느 구간에도 안 들어가서 **NaN** 이 된다.
`include_lowest=True` 를 주면 첫 구간이 `[46, 107.33]` 이 되어 46 도 포함된다.

#### 경계값을 직접 정해도 된다

`np.histogram` 은 **같은 간격**으로만 나눈다. 원하는 기준이 있으면 직접 리스트로 준다.

```python
ages = pd.Series([10, 25, 40, 70])
pd.cut(ages, bins=[0, 19, 64, 120], labels=['청소년', '성인', '노인'])
```

```
['청소년', '성인', '성인', '노인']
```

> 💡 구간 분할 후에는 `pd.get_dummies(df['hp_bin'])` 로 **원-핫 인코딩**해서 모델에 넣을 수 있다. (`04. 데이터전처리1` 참고)

## 5. 정규화 (Normalization)

**열마다 다른 숫자 범위를 0 ~ 1 (또는 -1 ~ 1) 로 맞추는 것.**

마력은 46 ~ 230, 연비는 9 ~ 46 ... 범위가 다르면 큰 숫자 열이 분석을 좌지우지한다.
→ 범위를 맞춰서 **열끼리 공평하게 비교**할 수 있게 만든다.

```python
import numpy as np
import pandas as pd

# 데이터를 새로 불러옴 (앞 셀에서 df가 바뀌었을 수 있으므로)
df = pd.read_csv("./data/auto-mpg.csv", header=None)
df.columns = [...]   # 위와 같음

df['horsepower'] = df['horsepower'].replace('?', np.nan)
df.dropna(subset=['horsepower'], axis=0, inplace=True)
df['horsepower'] = df['horsepower'].astype('float')

# 정규화 전 horsepower 통계 확인
print(df.horsepower.describe())
```

```

mean     104.469388
std       38.491160
min       46.000000
25%       75.000000
50%       93.500000
75%      126.000000
max      230.000000
Name: horsepower, dtype: float64
```

> 💡 `df.horsepower` = `df['horsepower']` 와 같다. (열 이름에 띄어쓰기가 없을 때만 점(.)으로 접근 가능)

### 방법 1 : 최대값으로 나누기 (수업에서 한 방법)

```python
df.horsepower = df.horsepower / abs(df.horsepower.max())   # abs : 절대값

print(df.horsepower.head())
print(df.horsepower.describe())
```

```
count    392.000000

std        0.167353
min        0.200000      ← 46 / 230 (0 이 아님!)
25%        0.326087
50%        0.406522
75%        0.547826
max        1.000000      ← 230 / 230
```

- **`abs()` 를 쓰는 이유** : 음수가 섞인 데이터라면 최대 "절대값" 으로 나눠야 **-1 ~ 1** 범위가 된다
- 이 방법은 **최대값만 1** 로 맞추고, 최소값은 0 이 안 된다 (여기서는 0.2)

### 방법 2 : Min-Max 정규화 (정확히 0 ~ 1)

```python
# (값 - 최소값) / (최대값 - 최소값)
hp = df.horsepower
df.horsepower = (hp - hp.min()) / (hp.max() - hp.min())
```

| 원래 값 | 방법 1 : 값 / 230 | 방법 2 : (값-46) / 184 |
|---|---|---|
| 46 (최소) | 0.200 | **0.000** |
| 95 | 0.413 | 0.266 |
| 130 | 0.565 | 0.457 |
| 230 (최대) | 1.000 | **1.000** |

> 💡 방법 2 는 sklearn 의 **`MinMaxScaler`** 와 같은 계산이다. (`04. 데이터전처리1` 참고)

## 6. 시계열 데이터

**시계열(time series)** = 시간 순서대로 기록된 데이터. (주가, 기온, 매출 ...)

### pandas 의 시간 자료형 2가지

| 자료형 | 뜻 | 비유 | 예 |
|---|---|---|---|
| **Timestamp** | 특정 **시점** (한 순간) | 시계의 한 점 📍 | `2019-01-01 00:00:00` |
| **Period** | **기간** (일정한 길이의 구간) | 달력의 한 칸 📅 | `2019-01` = 2019년 1월 한 달 전체 |

```python
pd.Period('2019-01', freq='M').start_time    # 2019-01-01 00:00:00
pd.Period('2019-01', freq='M').end_time      # 2019-01-31 23:59:59.999999
```

→ Period `2019-01` 은 1월 1일 0시부터 1월 31일 끝까지 **한 달 전체**를 뜻한다.

#### Timestamp → Period : `to_period()`

```python
import pandas as pd

```


```python
# Timestamp를 Period로 변환

print(pr_month)
```


| `freq` | 뜻 | `2020-03-01` 의 결과 |
|---|---|---|

### 6-3. 시계열 데이터 활용

**`.dt` 로 꺼낼 수 있는 것들**

#### 날짜 인덱싱 : 날짜로 행 선택하기

**준비 : 날짜를 인덱스로 + 정렬**

```python
import pandas as pd

# 데이터를 새로 불러옴 (앞에서 Year, Month, Day 열을 추가했으므로)
df = pd.read_csv('./data/stock-data.csv')
df['new_Date'] = pd.to_datetime(df['Date'])

# new_Date 열을 인덱스로 지정 -> 날짜로 행 선택 가능 (한 번만 실행할 것)
df.set_index('new_Date', inplace=True)
# 날짜 오름차순 정렬 (원본은 최신 날짜부터 거꾸로 정렬되어 있음)
# 날짜 범위 슬라이싱(:)은 인덱스가 오름차순이어야 동작함
df.sort_index(inplace=True)
print(df.head())
```

> `KeyError: "None of ['new_Date'] are in the columns"`. → `read_csv` 셀부터 다시 실행

> ⚠️ **`df.loc['2018']` 이 `KeyError` 라면?** 인덱스가 날짜가 아니라 0, 1, 2 ... 라는 뜻. `set_index` 를 먼저!

#### ⚠️ 날짜 범위 슬라이싱은 정렬이 필수

원본 데이터는 **최신 날짜부터 거꾸로** (7/2 → 6/1) 정렬되어 있다. 정렬 안 하고 범위로 자르면

```python
df.loc['2018-06-08':'2018-06-20']    # sort_index() 안 한 상태
```

```
KeyError: 'Value based partial slicing on non-monotonic DatetimeIndexes with non-existing keys is not allowed.'
```

→ pandas 는 날짜 범위를 자를 때 인덱스가 **오래된 날짜 → 최신 날짜 (오름차순)** 이기를 기대한다.
→ 해결 : **`df.sort_index()`** 로 먼저 정렬

| 선택 방법 | 정렬 필요? |
|---|---|
| `df.loc['2018']`, `df.loc['2018-07']` (기간 하나) | ❌ 없어도 됨 |
| `df.loc['2018-06-08':'2018-06-20']` (범위 `:`) | ⭕ **필수** |

#### 보너스 : 기간별로 묶기 `resample()`

날짜 인덱스가 있으면 **주별, 월별** 집계가 한 줄로 된다.

## 7. 자주 만나는 에러

| 에러 메시지 | 원인 | 해결 |
|---|---|---|
| `NameError: name 'np' is not defined` | numpy 를 import 안 함 | `import numpy as np` |
| `ValueError: could not convert string to float: '?'` | `'?'` 가 남은 채로 `astype('float')` | `replace('?', np.nan)` → `dropna` 먼저 |
| `ValueError: Length mismatch: Expected axis has N elements, new values have 9 elements` | `df.columns = [...]` 개수가 실제 열 개수와 다름 | `read_csv` 부터 다시 실행 (df 가 다른 데이터로 바뀌어 있을 수 있음) |
| `KeyError: ['horseepower']` | 열 이름 오타 | 철자 확인 (`df.columns` 출력) |
| `AttributeError: module 'pandas' has no attribute 'to_detetime'` | 함수 이름 오타 | `pd.to_datetime` |
| `AttributeError: 'Series' object has no attribute 'bt'` | `.dt` 오타 | `.dt.year` |
| `NameError: name 'monthly' is not defined` | 계산 결과를 변수에 저장 안 함 | `monthly = df.groupby(...)...` |
| `KeyError: '2018'` (`df.loc['2018']`) | 인덱스가 날짜가 아님 | `df.set_index('new_Date')` 먼저 |
| `KeyError: "None of ['new_Date'] are in the columns"` | `set_index` 를 두 번 실행 | `read_csv` 셀부터 다시 실행 |
| `KeyError: 'Value based partial slicing on non-monotonic ...'` | 날짜 인덱스가 정렬 안 됨 | `df.sort_index()` |

> 💡 **Jupyter 에러의 절반은 "셀 실행 순서" 문제다.**
> Jupyter 는 셀을 **실행한 순서대로** 변수를 기억한다. 위에서 아래로 차례대로 실행하지 않으면
> `df` 가 엉뚱한 데이터(다른 예제의 df)로 남아 있을 수 있다.
> 이상하면 **커널 재시작 → 위에서부터 다시 실행**.

## 8. 한눈에 정리

### 코드 치트시트

| 하고 싶은 것 | 코드 |
|---|---|
| **누락 데이터** | |
| 열별 NaN 개수 | `df.isnull().sum()` |
| 열별 NaN 비율 | `df.isnull().mean()` |
| 값별 개수 (NaN 포함) | `df['열'].value_counts(dropna=False)` |
| NaN 있는 행 삭제 (특정 열 기준) | `df.dropna(subset=['열'], axis=0)` |
| 유효값 N개 미만인 열 삭제 | `df.dropna(axis=1, thresh=N)` |
| 평균으로 채우기 | `df['열'].fillna(df['열'].mean())` |
| 최빈값으로 채우기 | `df['열'].fillna(df['열'].value_counts().idxmax())` |
| 앞/뒤 값으로 채우기 | `df['열'].ffill()` / `bfill()` |
| **중복** | |
| 중복 여부 / 개수 | `df.duplicated()` / `df.duplicated().sum()` |
| 중복 행 제거 | `df.drop_duplicates()` |
| 특정 열 기준 중복 제거 | `df.drop_duplicates(subset=['열1', '열2'])` |
| **자료형** | |
| 열별 자료형 확인 | `df.dtypes` |
| 고유값 확인 | `df['열'].unique()` |
| 특정 값 → NaN | `df['열'].replace('?', np.nan)` |
| 자료형 변환 | `df['열'].astype('float')` / `astype('category')` |
| 숫자로 변환 (안 되면 NaN) | `pd.to_numeric(df['열'], errors='coerce')` |
| 값 바꾸기 (딕셔너리) | `df['열'].replace({1: 'USA', 2: 'EU'})` |
| **구간 분할 / 정규화** | |
| 같은 간격 경계값 구하기 | `count, bins = np.histogram(df['열'], bins=3)` |
| 구간 나누고 이름 붙이기 | `pd.cut(x=..., bins=..., labels=..., include_lowest=True)` |
| 최대값으로 정규화 | `df['열'] / abs(df['열'].max())` |
| Min-Max 정규화 | `(x - x.min()) / (x.max() - x.min())` |
| **시계열** | |
| 문자열 → 날짜 | `pd.to_datetime(df['Date'])` |
| 날짜 열 → 인덱스 | `df.set_index('new_Date', inplace=True)` |
| 날짜 인덱스 정렬 | `df.sort_index(inplace=True)` |
| 연/월/일 꺼내기 | `df['날짜'].dt.year` / `.dt.month` / `.dt.day` |
| 날짜 → 월 기간 | `df['날짜'].dt.to_period('M')` |
| 날짜 배열 만들기 | `pd.date_range(start=..., periods=..., freq='MS')` |
| 기간 배열 만들기 | `pd.period_range(start=..., periods=..., freq='M')` |
| 날짜로 행 선택 | `df.loc['2018-07']` |
| 날짜 범위 선택 | `df.loc['2018-06-08':'2018-06-20']` (정렬 필수) |
| 월별 집계 | `df.groupby('거래월')['거래량'].sum()` |
| 변화율 | `시리즈.pct_change() * 100` |
| 주별/월별 집계 (날짜 인덱스) | `df['열'].resample('W').mean()` |

### 꼭 기억할 7가지

1. **NaN 확인은 `df.isnull().sum()` 부터**
2. **`dropna()` 는 `subset` 을 꼭 지정** (안 하면 데이터가 확 줄어든다)
3. **숫자는 평균/중앙값, 글자는 최빈값으로 채우기** (이상치 많으면 중앙값)
4. **`fillna`, `replace`, `astype` 은 결과를 다시 대입해야 반영된다** (`df['열'] = ...`)
5. **숫자 열이 `str` 이면 `unique()` 로 이상한 값(`'?'`)부터 찾기**
6. **날짜는 `pd.to_datetime` 으로 변환 → `set_index` → `sort_index`**
7. **Jupyter 에러가 이상하면 위에서부터 다시 실행**
