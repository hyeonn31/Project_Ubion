## 0. 큰 그림 먼저

### 함수 매핑이란?

**매핑(mapping)** = "짝지어 주기". 데이터의 각 부분을 함수에 넣고, 나온 결과와 짝지어 주는 것.

```
데이터 :  22  →  38  →  26  →  ...
           ↓      ↓      ↓
함수   :  +10    +10    +10
           ↓      ↓      ↓
결과   :  32     48     36    ...
```

for 문을 직접 안 써도 pandas 가 **알아서 하나씩 꺼내서 함수에 넣고, 결과를 모아** 준다.

### 핵심 : 함수에 "무엇을" 넣어 주느냐

오늘 배운 것은 결국 **함수에 넣는 단위**의 차이다.

| 단원 | 함수에 들어가는 것 | 도구 | 함수 실행 횟수 (891행 x 2열 기준) |
|---|---|---|---|
| 1-1 | **원소(칸) 하나** (숫자 하나) | `Series.apply()`, `Series.map()`, `DataFrame.map()` | 칸 수만큼 (1,782번) |
| 1-2 | **시리즈 하나** (열 한 줄 또는 행 한 줄) | `DataFrame.apply()` | 열 수(2번) 또는 행 수(891번) |
| 1-3 | **데이터프레임 통째로** | `DataFrame.pipe()` | 딱 1번 |

### 엑셀로 비유하면

```
         age    fare
   0    22.0    7.25     ← 행(가로줄)
   1    38.0   71.28
   2    26.0    7.93
         ↑
       열(세로줄)
```

| 도구 | 엑셀로 치면 |
|---|---|
| `map` | **칸마다** 같은 수식 적용 (모든 칸에 +10) |
| `apply` (기본, `axis=0`) | **세로줄마다** 답 하나 (열마다 최대값) |
| `apply(axis=1)` | **가로줄마다** 답 하나 (행마다 age + fare) |
| `pipe` | **표 전체**를 한 번에 함수에 넘김 |

## 준비 : 함수와 lambda 복습

### 사용자 함수 정의

```python
# 사용자 함수 정의
def add_10(n):            # 숫자 n을 받아서 10을 더한 값을 반환
    return n + 10

def add_two_obj(a, b):    # 두 값 a, b를 받아서 더한 값을 반환
    return a + b
```

```python
# 함수가 잘 동작하는지 숫자로 먼저 테스트
print(add_10(10))           # 10 + 10 = 20
print(add_two_obj(10, 10))  # 10 + 10 = 20
```

```
20
20
```

> 💡 **함수는 데이터에 적용하기 전에 숫자 하나로 먼저 테스트**하는 습관!
> 함수가 틀렸는지, 적용 방법이 틀렸는지 구분할 수 있다.

### `return` vs `print`

```python
def add_10(n):
    print("처리중:", n)     # 화면에 보여 주기만 함 (결과로 안 남음)
    return n + 10          # 함수를 부른 쪽에 값을 돌려줌 (결과로 남음)
```

| | `print()` | `return` |
|---|---|---|
| 하는 일 | 화면에 출력 | 값을 돌려줌 |
| `apply` 결과에 들어가나? | ❌ | ⭕ |
| 없으면? | 화면에 안 보일 뿐 | 결과가 전부 `None` |

→ `apply`, `map` 에 쓰는 함수는 반드시 **`return` 으로 값을 돌려줘야** 한다.

### lambda 함수 : 이름 없는 한 줄 함수

```python
# def 로 만든 함수
def add_10(n):
    return n + 10

# 똑같은 함수를 lambda 로
lambda n: n + 10
```

```
lambda  매개변수 :  돌려줄 값
lambda    n     :   n + 10
```

| | `def` | `lambda` |
|---|---|---|
| 이름 | 있음 (`add_10`) | 없음 |
| 길이 | 여러 줄 가능 | **한 줄**만 |
| `return` | 직접 씀 | 자동 (`:` 뒤가 곧 return 값) |
| 쓰는 곳 | 여러 번 재사용, 복잡한 로직 | **한 번만 쓰는 짧은 함수** |

#### lambda 안에 조건문 : 조건부 표현식

```python
lambda x: x * 1.10 if x >= 100000 else 0
```

```
  x * 1.10      if   x >= 100000    else    0
 ─────────          ─────────────          ───
 참일 때 값            조건             거짓일 때 값
```

읽는 법 : "**x * 1.10 을 돌려줘, 만약 x 가 100000 이상이면. 아니면 0.**"

> ⚠️ 일반 if 문과 순서가 다르다! **참일 때 값이 맨 앞**에 온다.
> `elif` 는 못 쓴다. 조건이 3개 이상이면 `def` 로 만드는 게 읽기 쉽다.

```python
# 같은 내용 (def 버전)
def target(x):
    if x >= 100000:
        return x * 1.10
    else:
        return 0
```

## 1-1. 개별 원소에 함수 매핑

**원소(칸) 하나하나에 함수를 적용한다.** 함수 안의 `x` 는 **숫자 하나** (또는 글자 하나).

### 실습 데이터

```python
import seaborn as sns

titanic = sns.load_dataset('titanic')
df = titanic.loc[:, ['age', 'fare']]    # 모든 행, age와 fare 열만 선택
df['ten'] = 10                          # 모든 행에 10이 들어간 새 열 ten 추가
print(df.head())
```

```
    age     fare  ten
0  22.0   7.2500   10
1  38.0  71.2833   10
2  26.0   7.9250   10
3  35.0  53.1000   10
4  35.0   8.0500   10
```

| 코드 | 뜻 |
|---|---|
| `titanic.loc[:, ['age', 'fare']]` | `:` = 모든 행, `['age', 'fare']` = 이 두 열만 |
| `df['ten'] = 10` | 숫자 하나를 대입하면 **모든 행에 같은 값**이 들어간 새 열이 생김 |

### 시리즈 원소에 함수 매핑 : `Series.apply()`

```python
# 시리즈 객체에 적용
sr1 = df['age'].apply(add_10)
print(sr1.head())
```

```
0    32.0
1    48.0
2    36.0
3    45.0
4    45.0
Name: age, dtype: float64
```

#### 내부에서 일어나는 일

`df['age'].apply(add_10)` 한 줄은 이 for 문과 똑같다.

```python
results = []
for n in df['age']:              # age 값을 하나씩 꺼내서
    results.append(add_10(n))    # 함수에 넣고, return 값을 모음
pd.Series(results)               # 모은 값으로 새 시리즈 만들기 (인덱스는 원본과 같게)
```

```
22.0 → add_10(22.0) → 32.0
38.0 → add_10(38.0) → 48.0
26.0 → add_10(26.0) → 36.0
...   (891번 반복)
```

#### ⚠️ 함수 이름만! 괄호 붙이지 않기

```python
df['age'].apply(add_10)      # ⭕ 함수 자체를 넘김 → apply 가 나중에 하나씩 호출
df['age'].apply(add_10())    # ❌ 지금 바로 add_10() 을 실행 → 인수가 없어서 에러
```

```
TypeError: add_10() missing 1 required positional argument: 'n'
```

> 💡 비유 : `apply(add_10)` = "이 **요리사**한테 재료 하나씩 줘"
> `apply(add_10())` = "요리사한테 **지금 당장 빈손으로** 요리하라고 함" → 재료가 없다는 에러

#### 🔍 실험 : print 와 return 의 순서

```python
# test code
def add_10(n):
    print("처리중:", n)
    return n + 10

df['age'].apply(add_10)
```

```
처리중: 22.0
처리중: 38.0
처리중: 26.0
...
처리중: nan
...
처리중: 32.0      ← 891개 처리중이 먼저 쭉 나오고

0      32.0       ← 마지막에 결과 시리즈가 한꺼번에 나온다
1      48.0
...
```

**왜 "처리중" 만 먼저 쭉 나올까?** 실제로는 `print → return → print → return ...` 이 **번갈아** 실행된다.

| | 언제 화면에 나오나 |
|---|---|
| `print()` | 호출될 때마다 **바로** 출력 |
| `return` | 화면에 안 나오고 `apply` 에게 값만 넘김 (조용히 보관) |

`apply` 가 891개를 다 모은 뒤, 셀의 마지막 줄 결과(시리즈)를 Jupyter 가 **한 번에 보여 주는 것**이다.

**처리중과 결과를 세트로 보고 싶다면**

```python
def add_10(n):
    result = n + 10
    print("처리중:", n, "→ 결과:", result)
    return result

df['age'].apply(add_10)
```

```
처리중: 22.0 → 결과: 32.0
처리중: 38.0 → 결과: 48.0
처리중: 26.0 → 결과: 36.0
...
처리중: nan → 결과: nan       ← NaN 에 뭘 더해도 NaN
```

> 💡 맨 아래 시리즈 출력이 싫으면 결과를 변수에 담는다 : `df['age_plus10'] = df['age'].apply(add_10)`
> 셀의 마지막 줄이 **대입문**이면 Jupyter 는 아무것도 자동 출력하지 않는다.

#### 인수가 2개 이상인 함수 : 나머지는 키워드로

```python
# 시리즈 객체와 숫자에 적용 : 2개의 인수 (시리즈 + 숫자)
sr2 = df['age'].apply(add_two_obj, b=10)
print(sr2.head())
```

```
0    32.0
1    48.0
2    36.0
3    45.0
4    45.0
Name: age, dtype: float64
```

```
add_two_obj(a, b)
            ↑  ↑
            │  └── b=10 : apply 에 키워드로 직접 넘김
            └───── age 열의 원소가 하나씩 자동으로 들어감 (항상 첫 번째 인수)
```

> 💡 **원소는 항상 함수의 첫 번째 인수**로 들어간다. 나머지 인수는 `b=10` 처럼 이름을 붙여서 넘긴다.
> 위치로 넘기고 싶으면 `args=` 를 쓴다 → `df['age'].apply(add_two_obj, args=(10,))`
> (`(10,)` 처럼 **쉼표** 필수. 쉼표가 있어야 튜플이 된다)

```python
# 인수 3개인 함수
def add3(a, b, c):
    return a + b + c

df['age'].apply(add3, args=(10,), c=100)    # a=원소, b=10, c=100 → 22 + 10 + 100 = 132
```

#### lambda 함수로 적용

```python
# 람다 함수 활용 : 시리즈 객체에 적용
sr3 = df['age'].apply(lambda x: add_10(x))    # x : age 열의 원소 하나 (22.0, 38.0, ...)
```

→ `apply(add_10)` 과 결과가 같다. lambda 가 받은 `x` 를 그대로 `add_10` 에 넘길 뿐.

**lambda 가 빛나는 순간 : 조건이 붙을 때**

```python
# 짝수 나이에만 10을 더하고, 홀수면 그대로
sr3 = df['age'].apply(lambda x: add_10(x) if x % 2 == 0 else x)
print(sr3.head())
```

```
0    32.0      ← 22 짝수 → 22 + 10
1    48.0      ← 38 짝수 → 38 + 10
2    36.0      ← 26 짝수 → 26 + 10
3    35.0      ← 35 홀수 → 그대로
4    35.0      ← 35 홀수 → 그대로
Name: age, dtype: float64
```

| 코드 | 뜻 |
|---|---|
| `x % 2` | x 를 2로 나눈 **나머지** (짝수면 0, 홀수면 1) |
| `x % 2 == 0` | 짝수인가? |

> 참고 : NaN 은 `NaN % 2 == 0` 이 False 라서 `else x` 로 가고, 그대로 NaN 이 된다.

### 데이터프레임 원소에 함수 매핑 : `DataFrame.map()`

**데이터프레임의 모든 칸**에 함수를 하나씩 적용한다.

```python
import seaborn as sns

titanic = sns.load_dataset('titanic')
df = titanic.loc[:, ['age', 'fare']]
print(df.head())
```

```
    age     fare
0  22.0   7.2500
1  38.0  71.2833
2  26.0   7.9250
3  35.0  53.1000
4  35.0   8.0500
```

```python
def add_10(n):
    return n + 10

df_map = df.map(add_10)
print(df_map.head())
```

```
    age     fare
0  32.0  17.2500      ← 22 + 10,  7.25 + 10
1  48.0  81.2833      ← 38 + 10, 71.28 + 10
2  36.0  17.9250
3  45.0  63.1000
4  45.0  18.0500
```

```
   age     fare               함수가 받는 x
  22.0     7.25      →   22.0, 7.25, 38.0, 71.28, 26.0, 7.93 ...
  38.0    71.28           (칸 하나씩, 891 x 2 = 1,782번 실행)
  26.0     7.93
```

→ **결과 모양 = 원본 모양** (891행 x 2열 그대로)

> ⚠️ **`applymap` 은 이제 없다!**
> 예전 책·블로그에서는 `df.applymap(함수)` 를 썼는데, pandas 2.1 부터 `df.map(함수)` 로 이름이 바뀌었고,
> pandas 3.0 에서는 `applymap` 이 **완전히 삭제**되었다. → 옛날 코드를 보면 `applymap` → `map` 으로 바꿔 쓰기.

#### 예제 1. 종가에 10% 목표 수익률 적용 (시리즈 원소)

```python
def target_price(price):        # 가격을 받아서 10% 올린 가격을 반환
    return price * 1.10

# 종가 열의 원소를 하나씩 target_price에 넣고, 결과를 새 열 '목표가'로 추가
df['목표가'] = df['종가'].apply(target_price)
# df['목표가'] = df['종가'].map(target_price)     ← 이렇게 써도 결과 같음
df.head()
```

```
       종목      종가  수익률(%)      거래량       목표가
0    삼성전자   70000     2.5  1000000   77000.0
1  SK하이닉스  180000    -1.2   800000  198000.0
2     현대차  250000     3.8   450000  275000.0
3     카카오   55000    -0.5  1200000   60500.0
```

- **새 열 만들기** : `df['새열이름'] = 값` (없는 열 이름에 대입하면 자동으로 추가)
- `* 1.10` = 10% 증가 (원래 값 100% + 10%)
- 결과가 `77000.0` 처럼 **소수점**이 붙는 이유 : `1.10` 이 실수(float)라서 결과도 실수

> ⚠️ 자주 하는 실수 : `df.pd.DataFrame['목표가'] = 0` → `AttributeError: 'DataFrame' object has no attribute 'pd'`
> 새 열은 그냥 **`df['목표가'] = ...`** 로 만든다.

> 💡 **열 하나(시리즈)에서는 `apply` 와 `map` 결과가 같다.** 둘 다 원소 하나씩 처리하기 때문.

#### 예제 2. 수익률에 따라 매수·매도 신호 만들기 (조건이 여러 개)

```python
def trading_signal(rate):
    if rate >= 3:
        return '강한 상승'
    elif rate > 0:
        return '상승'
    elif rate <= -1:
        return '하락'
    else:
        return '약보합'

df['시장신호'] = df['수익률(%)'].apply(trading_signal)
df.head()
```

```
1  SK하이닉스  180000    -1.2   800000  198000.0     하락
```

**조건 판단 과정**

| 종목 | 수익률 | `>= 3`? | `> 0`? | `<= -1`? | 결과 |
|---|---|---|---|---|---|
| 삼성전자 | 2.5 | ❌ | ⭕ | | **상승** |
| SK하이닉스 | -1.2 | ❌ | ❌ | ⭕ | **하락** |
| 현대차 | 3.8 | ⭕ | | | **강한 상승** |

> 그래서 `>= 3` 을 `> 0` 보다 **먼저** 써야 한다. 순서를 바꾸면 3.8 도 `> 0` 에 먼저 걸려서 '상승' 이 된다.

> 💡 **조건이 3개 이상이면 lambda 보다 def** 가 훨씬 읽기 좋다. (lambda 에는 elif 가 없다)

```python
def target_price(price):
```

```python
df['목표가'] = df['종가'].apply(target_price_if)
```

## 1-2. 시리즈 객체에 함수 매핑 : `DataFrame.apply()`

이번에는 **원소 하나가 아니라 시리즈 하나(열 한 줄 또는 행 한 줄)를 통째로** 함수에 넣는다.

```python
df.apply(함수, axis=0)     # 기본값 : 열(세로줄)을 하나씩 → 함수 x = 열 전체
df.apply(함수, axis=1)     # 행(가로줄)을 하나씩 → 함수 x = 행 전체
```

| `axis` | 함수에 들어가는 것 | 실행 횟수 (891행 x 2열) | 외우는 법 |
|---|---|---|---|
| `0` (기본) | **열** 하나 (세로로 891개짜리 시리즈) | 2번 | 0 = 세로로 쭉 내려가며 묶음 |
| `1` | **행** 하나 (가로로 2개짜리 시리즈) | 891번 | 1 = 가로로 쭉 가며 묶음 |

> 💡 `axis` 는 **"결과가 어디에 들어가나"** 가 아니라 **"함수에 무엇을 넣어 주나"** 를 정한다.

### 데이터프레임의 각 열에 함수 매핑 (`axis=0`)

#### ① 리턴값이 시리즈 → 결과는 데이터프레임

```python
import seaborn as sns

titanic = sns.load_dataset('titanic')
df = titanic.loc[:, ['age', 'fare']]
```

```python
# 사용자 함수 정의
def missing_value(series):    # 시리즈(열 하나)를 인수로 전달받음
    return series.isnull()    # 불린(Boolean) 시리즈를 반환 (칸마다 True/False)

# 데이터프레임의 각 열을 인수로 전달하면 데이터프레임을 반환
result = df.apply(missing_value, axis=0)
print(result.head())
print(type(result))
```

```
1  False  False
2  False  False
3  False  False
4  False  False

```

**과정**

```
1번째 실행 : x = age 열 전체 [22.0, 38.0, 26.0, ..., NaN, ...]  → isnull() → [False, False, ..., True, ...] (891개)
2번째 실행 : x = fare 열 전체 [7.25, 71.28, 7.93, ...]          → isnull() → [False, False, ...] (891개)

→ 891개짜리 시리즈 2개를 옆으로 붙임 → 891행 x 2열 데이터프레임
```

#### ② 리턴값이 원소(값 하나) → 결과는 시리즈

```python
def min_max(x):
    return x.max() - x.min()     # 열 하나를 받아서 (최대값 - 최소값) 숫자 하나를 반환

# 데이터프레임의 각 열을(시리즈) 인수로 전달하면 시리즈를 반환
result = df.apply(min_max)       # 기본값 axis=0
print(result)
print(type(result))
```

```

fare    512.3292
dtype: float64

<class 'pandas.Series'>
```

**과정**

```
1번째 실행 : x = age 열 전체  → max 80.0  - min 0.42 = 79.58    (숫자 하나)
2번째 실행 : x = fare 열 전체 → max 512.33 - min 0.0  = 512.33  (숫자 하나)

→ 숫자 2개를 모음 → 시리즈 (인덱스 = 열 이름)
```

> 💡 `x.max() - x.min()` 을 **범위(range)** 라고 한다. 데이터가 얼마나 넓게 퍼져 있는지 보여 준다.
> (age 의 최소값 0.42 = 생후 5개월 아기)

#### 리턴값에 따라 결과 모양이 달라진다

| 함수가 돌려주는 것 | `df.apply()` 결과 | 예 |
|---|---|---|
| **시리즈** (열과 같은 길이) | **데이터프레임** | `x.isnull()`, `x * 2`, `x / x.max()` |
| **값 하나** (숫자, 글자) | **시리즈** | `x.max()`, `x.mean()`, `x.max() - x.min()` |

> ⚠️ **`map` 에 열 단위 함수를 넣으면 에러**
> `df.map(max)` → `TypeError: 'float' object is not iterable`
> `map` 은 숫자 **하나**를 넘기는데, `max` 는 여러 개(묶음)가 필요하기 때문.
> → 열 단위 계산은 **`apply`** 로!

### 데이터프레임의 각 행에 함수 매핑 (`axis=1`)

**같은 행에 있는 여러 열의 값을 함께 써서** 계산할 때 쓴다.

```python
import seaborn as sns

titanic = sns.load_dataset('titanic')
df = titanic.loc[:, ['age', 'fare']]
df['ten'] = 10
print(df.head())
```

```
    age     fare  ten
0  22.0   7.2500   10
1  38.0  71.2833   10
2  26.0   7.9250   10
3  35.0  53.1000   10
4  35.0   8.0500   10
```

```python
def add_two_obj(a, b):
    return a + b

# axis=1 : 행을 하나씩 x 로 넘김 → x['age'], x['ten'] 으로 그 행의 값을 꺼냄
df['add'] = df.apply(lambda x: add_two_obj(x['age'], x['ten']), axis=1)   # 행 연산
print(df.head())
```

```
    age     fare  ten   add
0  22.0   7.2500   10  32.0
1  38.0  71.2833   10  48.0
2  26.0   7.9250   10  36.0
3  35.0  53.1000   10  45.0
4  35.0   8.0500   10  45.0
```

**과정**

```
         age   fare   ten
행 0 →  22.0   7.25   10    x = 이 행 전체   → x['age'] + x['ten'] = 22 + 10 = 32
행 1 →  38.0  71.28   10    x = 이 행 전체   → x['age'] + x['ten'] = 38 + 10 = 48
행 2 →  26.0   7.93   10    x = 이 행 전체   → x['age'] + x['ten'] = 26 + 10 = 36
...  (891번)

→ 행마다 답 하나씩 → 891개를 세로로 쌓으면 → 열 하나 → df['add'] 에 넣음
```

**Q. 결과가 "열" 인데 왜 `axis=1` (행) 인가?**
→ `axis=1` 은 "**행을 하나씩 함수에 넣어라**" 는 뜻이다. 행마다 답이 하나씩 나오니까, 그 답들을 모으면 **세로 한 줄(열)** 이 되는 것.
`age` 와 `ten` 을 더하려면 **같은 행에 있는 두 값**이 필요하니까 행 단위로 넣는 것이다.

> 💡 `x` 는 행 하나(시리즈)라서 **`x['열이름']`** 으로 그 행의 값을 꺼낼 수 있다.
> 행 x 의 모습 : `age 22.0 / fare 7.25 / ten 10` (인덱스가 열 이름인 시리즈)

#### 💡 사실 이 정도는 apply 없이 된다 (벡터 연산)

```python
# 방법 1 : 시리즈끼리 바로 더하기 (같은 행끼리 자동으로 더해짐) ← 가장 간단, 가장 빠름
df['add'] = df['age'] + df['ten']

# 방법 2 : 만든 함수에 시리즈를 통째로 넣기 (함수 안의 a + b 가 시리즈끼리 덧셈이 됨)
df['add'] = add_two_obj(df['age'], df['ten'])

# 방법 3 : apply 행 연산 (수업에서 한 방법)
df['add'] = df.apply(lambda x: add_two_obj(x['age'], x['ten']), axis=1)
```

→ 셋 다 결과는 같다. pandas 는 **열끼리 `+ - * /` 를 하면 같은 행끼리 알아서 계산**해 준다.
→ `apply(axis=1)` 은 **if 문 같은 복잡한 로직**이 필요할 때 쓴다. (예 : "age 가 18 미만이면 fare 반값")

```python
# apply(axis=1) 이 꼭 필요한 예 : 행마다 조건 판단
df['할인요금'] = df.apply(lambda x: x['fare'] * 0.5 if x['age'] < 18 else x['fare'], axis=1)
```

> (참고 : 이것도 `np.where(df['age'] < 18, df['fare'] * 0.5, df['fare'])` 로 벡터 연산 가능 → [3-3](#3-3-속도--apply-는-느리다--벡터-연산을-먼저-생각하기) 참고)

## 1-3. 데이터프레임 객체에 함수 매핑 : `pipe()`

**데이터프레임 전체를 통째로** 함수에 넣는다. 함수는 **딱 한 번** 실행된다.

```python
df.pipe(함수)   ==   함수(df)       # 결과가 똑같다
```

```python
import seaborn as sns

titanic = sns.load_dataset('titanic')
df = titanic.loc[:, ['age', 'fare']]
print(df.head())
```

### 함수 3개 정의 : 단계적으로 쌓기

```python
# 각 열의 NaN 찾기 - 데이터프레임 전달하면 데이터프레임을 반환
def missing_value(x):
    return x.isnull()

# 각 열의 NaN 개수 반환 - 데이터프레임 전달하면 시리즈 반환
def missing_count(x):
    return missing_value(x).sum()

# 데이터프레임의 총 NaN 개수 - 데이터프레임 전달하면 값을 반환
def total_number_missing(x):
    return missing_count(x).sum()
```

함수가 **앞에서 만든 함수를 불러 쓰면서** 한 단계씩 쌓인다.

```
missing_value(df)          →  df.isnull()                   → 데이터프레임 (True/False 표)
missing_count(df)          →  df.isnull().sum()             → 시리즈 (열별 NaN 개수)
total_number_missing(df)   →  df.isnull().sum().sum()       → 숫자 하나 (전체 NaN 개수)
```

### ① 데이터프레임 → 데이터프레임

```python
result_df = df.pipe(missing_value)
print(result_df.head())
print(type(result_df))
```

```
     age   fare
0  False  False
1  False  False
2  False  False
3  False  False
4  False  False
<class 'pandas.DataFrame'>
```

### ② 데이터프레임 → 시리즈

```python
result_series = df.pipe(missing_count)
print(result_series)
print(type(result_series))
```

```
age     177
fare      0
dtype: int64
<class 'pandas.Series'>
```

### ③ 데이터프레임 → 값 하나

```python
result_value = df.pipe(total_number_missing)
print(result_value)
print(type(result_value))
```

```
177
<class 'numpy.int64'>
```

> ⚠️ 노트북에서 `age, fare, ten, add` 4열에 결과가 `354` 로 나왔다면, **데이터를 다시 불러오는 셀을 실행 안 해서**
> 앞 예제의 `df`(ten, add 열이 추가된 것)가 그대로 남아 있었기 때문이다.
> `add` 열은 `age + 10` 이라서 age 가 NaN 이면 add 도 NaN → 177 + 177 = 354.
> **Jupyter 는 셀을 실행한 순서대로 변수를 기억한다** → `df = titanic.loc[...]` 셀부터 다시 실행하면 177.

| 함수가 돌려주는 것 | `pipe()` 결과 |
|---|---|
| 데이터프레임 | 데이터프레임 |
| 시리즈 | 시리즈 |
| 값 하나 | 값 하나 (`numpy.int64` = 넘파이 정수) |

→ `pipe` 는 **함수가 돌려준 걸 그대로** 돌려준다. 모양을 바꾸지 않는다.

### 그럼 `pipe` 는 왜 쓰나? → 체이닝(줄줄이 연결)

`함수(df)` 와 결과가 같은데 굳이 `pipe` 를 쓰는 이유는 **여러 단계를 순서대로 읽기 좋게** 연결할 수 있어서다.

```python
# pipe 없이 : 안쪽부터 읽어야 함 (C → B → A 순서인데 A 가 맨 앞)
result = 함수C(함수B(함수A(df), 인수=1), 인수=2)

# pipe 로 : 위에서 아래로, 실행 순서대로 읽힌다
result = (df
          .pipe(함수A)
          .pipe(함수B, 인수=1)
          .pipe(함수C, 인수=2))
```

**예시**

```python
def add_col(d, name, val):       # 새 열을 추가한 데이터프레임을 반환
    d = d.copy()                 # 원본을 바꾸지 않으려고 복사
    d[name] = val
    return d

result = (df
          .pipe(lambda d: d.dropna())     # 1. NaN 행 삭제
          .pipe(add_col, 'ten', 10)       # 2. ten 열 추가 (인수는 apply 처럼 뒤에)
          .pipe(missing_count))           # 3. 열별 NaN 개수
```

> 💡 비유 : `pipe` = **파이프(관)**. 데이터가 관을 따라 흐르면서 한 단계씩 가공된다.
> 바깥을 괄호 `( )` 로 감싸면 `.pipe` 마다 줄을 바꿔 쓸 수 있다.

## 2. map vs apply vs pipe 완전 정리

### 한 장 요약

| | 시리즈 (열 하나) | 데이터프레임 |
|---|---|---|
| **`map`** | 원소 하나씩 (+ 딕셔너리로 값 바꾸기 가능) | **칸(원소) 하나씩** |
| **`apply`** | 원소 하나씩 | **열(axis=0) 또는 행(axis=1) 통째로** |
| **`pipe`** | 시리즈 통째로 1번 | **데이터프레임 통째로 1번** |

### 같은 데이터로 비교

```
 종가     거래량
70000    1000000
180000    800000
250000    450000
```

**`map` : 모든 칸에 하나씩**

```python
df[['종가', '거래량']].map(lambda x: x / 1000)
```

```
 종가    거래량
  70     1000
 180      800
 250      450
```

→ 칸 6개 → 함수 **6번** 실행 → 결과도 **6칸** (표 모양 그대로)

**`apply` : 세로줄마다 하나씩**

```python
df[['종가', '거래량']].apply(lambda x: x.max())
```

```
종가       250000
거래량    1000000
```

→ 줄 2개 → 함수 **2번** 실행 → 줄마다 **답 하나**

**`pipe` : 표 전체를 한 번에**

```python
df[['종가', '거래량']].pipe(lambda x: x.max().max())
```

```
1000000
```

→ 표 1개 → 함수 **1번** 실행

### 헷갈릴 때 구분 팁

> **함수 안의 `x` 가 뭔지 생각하기**
> - `x` 가 **숫자 하나** → `map`
> - `x` 가 **숫자 여러 개 (열 또는 행)** → `apply`
> - `x` 가 **표 전체** → `pipe`

| 하고 싶은 것 | 쓰는 것 |
|---|---|
| 칸마다 값을 바꾸기 (천 원 단위, 10% 올리기, 등급 매기기) | `map` (열 하나면 `apply` 도 OK) |
| 열마다 답 하나 (최대값, 평균, 범위) | `apply` (`axis=0`) |
| 같은 행의 여러 열로 계산 (age + ten, 조건 판단) | `apply(axis=1)` |
| 표 전체를 받는 함수, 여러 단계 연결 | `pipe` |
| 값을 다른 값으로 바꿔 끼우기 (male → 남) | `Series.map(딕셔너리)` |

## 3. 더 알면 좋은 것들

### 3-1. `Series.map(딕셔너리)` : 값 바꿔 끼우기

`map` 만의 특기. **딕셔너리를 넣으면 "이 값은 저 값으로"** 바꿔 준다.

```python
titanic['sex'].head(5).map({'male': '남', 'female': '여'})
```

```
['남', '여', '여', '여', '남']
```

> ⚠️ 딕셔너리에 **없는 값은 NaN** 이 된다.
> ```python
> titanic['sex'].head(5).map({'male': '남'})        # female 이 딕셔너리에 없음
> # ['남', NaN, NaN, NaN, '남']
> ```
> 없는 값은 **그대로 두고** 싶으면 `replace` 를 쓴다.
> ```python
> titanic['sex'].head(5).replace({'male': '남'})
> # ['남', 'female', 'female', 'female', '남']
> ```

| | `map(딕셔너리)` | `replace(딕셔너리)` |
|---|---|---|
| 딕셔너리에 없는 값 | **NaN** | **원래 값 유지** |
| 쓰는 곳 | 모든 값을 빠짐없이 바꿀 때 | 일부 값만 바꿀 때 |

### 3-2. NaN 건너뛰기 : `na_action='ignore'`

```python
df['age'].map(lambda x: x + 10, na_action='ignore')
```

→ NaN 은 함수에 넣지 않고 **그냥 NaN 으로 둔다.** 함수 안에서 NaN 때문에 에러가 날 수 있을 때 유용.
(`DataFrame.map` 도 같은 옵션이 있다)

### 3-3. 속도 : apply 는 느리다 → 벡터 연산을 먼저 생각하기

`apply`/`map` 은 내부적으로 **파이썬 for 문**을 돈다. pandas 기본 연산(벡터 연산)은 **C 언어로 한 번에** 계산한다.

```python
big = pd.DataFrame({'a': np.random.rand(200000)})    # 20만 행

big['a'].apply(lambda x: x + 10)    # 약 0.038초
big['a'] + 10                       # 약 0.0005초   ← 약 70배 빠름
```

**apply 대신 쓸 수 있는 벡터 연산들**

| apply 로 하던 것 | 벡터 연산으로 |
|---|---|
| `df['age'].apply(lambda x: x + 10)` | `df['age'] + 10` |
| `df.apply(lambda r: r['age'] + r['ten'], axis=1)` | `df['age'] + df['ten']` |
| `df['종가'].apply(lambda x: x * 1.1 if x >= 100000 else 0)` | `np.where(df['종가'] >= 100000, df['종가'] * 1.1, 0)` |
| `df.map(lambda x: x / 1000)` | `df / 1000` |
| 조건 여러 개 (예제 2) | `np.select([조건1, 조건2, ...], [값1, 값2, ...], default=값)` |

**`np.where(조건, 참일 때, 거짓일 때)`** : 조건 하나짜리 if-else 를 열 전체에 한 번에

```python
import numpy as np
np.where(df['종가'] >= 100000, df['종가'] * 1.1, 0)
# [0., 198000., 275000., 0.]     ← 예제 3 과 같은 결과
```

**`np.select(조건 리스트, 값 리스트, default=나머지)`** : if-elif-else 를 열 전체에 한 번에

```python
r = df['수익률(%)']
df['시장신호'] = np.select(
    [r >= 3, r > 0, r <= -1],               # 조건들 (위에서부터 검사)
    ['강한 상승', '상승', '하락'],            # 각 조건이 참일 때 값
    default='약보합'                          # 아무 조건에도 안 맞으면
)
# ['상승', '하락', '강한 상승', '약보합']    ← 예제 2 와 같은 결과
```

> 💡 **우선순위** : ① 벡터 연산(`+`, `np.where`) → ② 안 되면 `map`/`apply` → ③ 그래도 안 되면 for 문
> 단, 데이터가 수천 행 정도면 속도 차이를 못 느낀다. **배울 때는 apply 로 이해하고, 실무에서는 벡터 연산을 먼저** 떠올리자.

### 3-4. apply 가 시리즈를 돌려주면 여러 열이 생긴다

**열마다 여러 개의 답**

```python
df.apply(lambda col: pd.Series({'min': col.min(), 'max': col.max()}))
```

```
      age     fare
min  22.0   7.2500
max  38.0  71.2833
```

**행마다 여러 개의 답 → 새 열 여러 개**

```python
df.apply(lambda row: pd.Series({'합': row['age'] + row['fare'],
                                '차': row['fare'] - row['age']}), axis=1)
```

```
          합        차
0   29.2500 -14.7500
1  109.2833  33.2833
2   33.9250 -18.0750
```

### 3-5. 여러 통계를 한 번에 : `agg()`

```python
df.agg(['min', 'max', 'mean'])          # 모든 열에 여러 함수
```

```
        age    fare
min    0.42    0.00
max   80.00  512.33
mean  29.70   32.20
```

```python
df.agg({'age': 'mean', 'fare': 'max'})  # 열마다 다른 함수
```

```
age      29.70
fare    512.33
```

→ 열 단위 요약은 `apply` 보다 `agg` 가 간결하다. (`agg` = aggregate, 집계)

### 3-6. 함수에 기본값 인수 주기

```python
def target_price(price, rate=1.1):      # rate 를 안 주면 1.1
    return price * rate

df['종가'].apply(target_price)              # 10% 상승
df['종가'].apply(target_price, rate=1.2)    # 20% 상승 → [84000, 216000, 300000, 66000]
```

→ 함수 하나로 여러 상황에 재사용할 수 있다.

### 3-7. 숫자에 천 단위 쉼표 넣기 (보기용)

```python
df[['종가']].map(lambda x: f'{x:,}')
```

```
        종가
0   70,000
1  180,000
```

> ⚠️ 결과가 **글자**가 되므로 계산에는 못 쓴다. 출력·보고서용으로만!

## 4. 자주 만나는 에러

| 에러 메시지 | 원인 | 해결 |
|---|---|---|
| `TypeError: add_10() missing 1 required positional argument: 'n'` | `apply(add_10())` 처럼 **괄호**를 붙임 | `apply(add_10)` 함수 이름만 |
| `NameError: name 'add_10' is not defined` | 함수 정의 셀을 실행 안 함 | `def` 셀부터 실행 |
| `KeyError: 'tex'` (`x['tex']`) | 열 이름 오타 | `x['ten']`, `df.columns` 로 확인 |
| `KeyError: 'age'` | 지금 `df` 가 다른 데이터 (예 : 금융 df) | 데이터 불러오는 셀 다시 실행 |
| `TypeError: unsupported operand type(s) for /: 'str' and 'int'` | 글자 열에 숫자 계산 | 숫자 열만 골라서 (`select_dtypes('number')`) |
| `TypeError: 'float' object is not iterable` | `map` 에 열 단위 함수(`max` 등)를 넣음 | `apply` 사용 |
| `AttributeError: 'DataFrame' object has no attribute 'applymap'` | pandas 3.0 에서 삭제됨 | `df.map(함수)` |
| `AttributeError: 'DataFrame' object has no attribute 'pd'` | `df.pd.DataFrame[...]` | 새 열은 `df['열'] = 값` |
| 결과가 전부 `None` | 함수에 `return` 이 없음 (print 만 함) | `return` 추가 |
| `NaN` 이 섞여 나옴 | 원본이 NaN 이거나, `map(딕셔너리)` 에 없는 값 | `na_action='ignore'`, `replace` 사용 |

> 💡 **Jupyter 에서는 같은 이름 `df` 를 계속 덮어쓴다.**
> 타이타닉 df → 금융 df → 다시 타이타닉 df ... 셀 실행 순서가 꼬이면 엉뚱한 df 가 남아 있다.
> 에러가 이상하면 `print(df.head())` 로 **지금 df 가 뭔지** 먼저 확인!

## 5. 한눈에 정리

### 코드 치트시트

| 하고 싶은 것 | 코드 |
|---|---|
| **원소 단위** | |
| 열의 원소마다 함수 적용 | `df['열'].apply(함수)` / `df['열'].map(함수)` |
| 인수 추가로 넘기기 | `df['열'].apply(함수, b=10)` / `apply(함수, args=(10,))` |
| 조건부 lambda | `df['열'].apply(lambda x: A if 조건 else B)` |
| 결과를 새 열로 | `df['새열'] = df['열'].apply(함수)` |
| 데이터프레임 모든 칸에 적용 | `df.map(함수)` |
| 숫자 열만 골라서 | `df.select_dtypes('number').map(함수)` |
| 값 바꿔 끼우기 (없으면 NaN) | `df['열'].map({'a': 'A', 'b': 'B'})` |
| 값 바꿔 끼우기 (없으면 유지) | `df['열'].replace({'a': 'A'})` |
| NaN 건너뛰기 | `map(함수, na_action='ignore')` |
| **열/행 단위** | |
| 열마다 함수 (열 → 값 하나) | `df.apply(함수)` → 시리즈 |
| 열마다 함수 (열 → 시리즈) | `df.apply(함수)` → 데이터프레임 |
| 행마다 함수 | `df.apply(lambda x: x['열1'] + x['열2'], axis=1)` |
| 여러 통계 한 번에 | `df.agg(['min', 'max', 'mean'])` |
| **데이터프레임 단위** | |
| 데이터프레임 통째로 함수에 | `df.pipe(함수)` |
| 여러 단계 연결 | `(df.pipe(f1).pipe(f2, 인수=1).pipe(f3))` |
| **더 빠른 대안 (벡터 연산)** | |
| 열 전체 계산 | `df['열'] + 10`, `df['열1'] + df['열2']` |
| 조건 1개 | `np.where(조건, 참값, 거짓값)` |
| 조건 여러 개 | `np.select([조건들], [값들], default=값)` |

### 결과 모양 정리

| 코드 | 함수 x | 함수가 돌려주는 것 | 최종 결과 |
|---|---|---|---|
| `Series.apply(f)` / `Series.map(f)` | 원소 | 값 | 시리즈 |
| `DataFrame.map(f)` | 원소 | 값 | 데이터프레임 (같은 모양) |
| `DataFrame.apply(f)` | 열 | 시리즈 | 데이터프레임 |
| `DataFrame.apply(f)` | 열 | 값 | 시리즈 (인덱스 = 열 이름) |
| `DataFrame.apply(f, axis=1)` | 행 | 값 | 시리즈 (인덱스 = 행 번호) → 새 열로 쓰기 좋음 |
| `DataFrame.pipe(f)` | 데이터프레임 | 무엇이든 | 함수가 돌려준 그대로 |

### 꼭 기억할 7가지

1. **함수 이름만 넘긴다** : `apply(add_10)` ⭕, `apply(add_10())` ❌
2. **함수는 반드시 `return`** 으로 값을 돌려준다 (print 는 화면 출력일 뿐)
3. **`map` = 칸 하나씩, `apply` = 열/행 통째로, `pipe` = 표 통째로**
4. **열 하나(시리즈)에서는 `apply` 와 `map` 결과가 같다**
5. **`axis=1` 은 "행을 하나씩 넣어라"** → `x['열이름']` 으로 같은 행의 값을 꺼내 쓴다
6. **`applymap` 은 삭제됨 → `df.map`**
7. **apply 전에 벡터 연산(`+`, `np.where`)으로 되는지 먼저 생각하기** (훨씬 빠름)
