## 0. 큰 그림 먼저

엑셀 파일, CSV 파일, 웹페이지 표... 데이터는 여러 모양의 "포장지"에 담겨 온다.
pandas 는 포장지를 뜯어서 **똑같은 모양의 표(DataFrame)** 로 바꿔 준다.
반대로 표를 다시 원하는 포장지에 싸서 저장할 수도 있다.

| 파일 종류 | 읽기 (파일 → 표) | 저장 (표 → 파일) |
|---|---|---|
| CSV | `pd.read_csv()` | `df.to_csv()` |
| Excel | `pd.read_excel()` | `df.to_excel()` |
| JSON | `pd.read_json()` | `df.to_json()` |   
| HTML(웹페이지 표) | `pd.read_html()` | `df.to_html()` |

> 💡 외우는 법 : **읽기는 `pd.` 로 시작** (pandas 야, 이 파일 읽어 줘)
> **저장은 `df.` 로 시작** (이 표야, 너 자신을 파일로 저장해)

### 파일 경로 읽는 법

```python
'./Data-Pandas/read_csv_sample.csv'
```

| 부분 | 뜻 |
|---|---|
| `.` | **지금 노트북이 있는 폴더** (src) |
| `/Data-Pandas` | 그 안의 Data-Pandas 폴더 |
| `/read_csv_sample.csv` | 그 안의 파일 |

> 노트북을 다른 폴더로 옮기면 `.` 의 위치도 바뀐다 → `FileNotFoundError` 가 나면 경로부터 확인!

## 1. CSV 파일 읽기

**CSV** = Comma-Separated Values = **쉼표(,)로 칸을 나눈 글자 파일**.
메모장으로 열면 이렇게 생겼다.

```
c0,c1,c2,c3      ← 첫 줄 : 열 이름
0,1,4,7
1,2,5,8
2,3,6,9
```

### 1-1. 기본으로 읽기

```python
import pandas as pd

file_path = './Data-Pandas/read_csv_sample.csv'

df1 = pd.read_csv(file_path) #header=0
print(df1)
```

```
   c0  c1  c2  c3
0   0   1   4   7
1   1   2   5   8
2   2   3   6   9
```

- `header=0` 이 **기본값** → "0번째 줄(첫 줄)이 열 이름이야" 라는 뜻
- 행 이름(인덱스)은 안 정해 줬으니 0, 1, 2 가 자동으로 붙는다

### 1-2. `header=None` : "열 이름 줄 없어!"

```python
df2 = pd.read_csv(file_path, header=None)
```

```
    0   1   2   3
0  c0  c1  c2  c3     ← 원래 열 이름이 데이터 취급됨
1   0   1   4   7
2   1   2   5   8
3   2   3   6   9
```

- 첫 줄도 그냥 데이터로 읽는다 → 열 이름은 0, 1, 2, 3 으로 자동 생성
- **언제 쓰나?** 파일에 열 이름 줄이 진짜로 없을 때 (아래 `auto-mpg.csv` 가 그런 파일)

> ⚠️ 열 이름이 있는 파일에 `header=None` 을 쓰면 `c0` 같은 글자가 숫자 칸에 섞여서
> 모든 열이 숫자가 아니라 **글자(문자열)** 가 된다 → 계산이 안 됨.

### 1-3. `index_col` : "이 열을 행 이름으로 써!"

```python
df3 = pd.read_csv(file_path, index_col=None)   # 기본값 = 1-1 과 똑같은 결과
df4 = pd.read_csv(file_path, index_col='c0')   # c0 열을 행 인덱스로
```

```
    c1  c2  c3
c0
0    1   4   7
1    2   5   8
2    3   6   9
```

- `index_col='c0'` = 읽으면서 바로 `set_index('c0')` 한 것과 같다
- `c0` 는 이제 **열이 아니라 행 이름표**라서 열 목록에서 빠진다

> 🔍 **코드 리뷰** : 4번 셀 주석이 `header=None 옵션` 으로 되어 있는데, 실제 코드는 `index_col=None` 이다.
> 주석을 `# index_col=None 옵션 (기본값이라 df1 과 같은 결과)` 으로 고치자.

## 2. Excel 파일 읽기

```python
file_path = './Data-Pandas/남북한발전전력량.xlsx'

  - 요즘 pandas 는 .xlsx 면 알아서 openpyxl 을 쓰므로 생략해도 된다
- 엑셀에 시트가 여러 개면 `sheet_name='시트이름'` 으로 고를 수 있다 (안 쓰면 첫 번째 시트)

### 결과에 `NaN` 이 보이는 이유

```
  전력량 (억㎾h) 발전 전력별  1990  1991 ...
0        남한     합계  1077  1186
1       NaN     수력    64    51
2       NaN     화력   484   573

엑셀에서 '남한' 칸이 **여러 줄을 합친 셀(병합 셀)** 이었기 때문이다.

## 3. JSON 파일 읽기

**JSON** = 딕셔너리처럼 `{ "이름": 값 }` 모양으로 저장하는 글자 파일. 웹에서 데이터 주고받을 때 많이 쓴다.

`read_json_sample.json` 의 생김새 (일부) :

```json
{
    "year":      {"pandas": 2008, "NumPy": 2006, "matplotlib": 2003},
    "developer": {"pandas": "Wes Mckinneye", ...},
    "opensource":{"pandas": "True", ...}
}
```

```python
df = pd.read_json('./Data-Pandas/read_json_sample.json')
print(df)
print(df.index)
```

```
            name  year        developer opensource
pandas            2008    Wes Mckinneye       True
NumPy             2006  Travis Oliphant       True
matplotlib        2003   John D. Hunter       True

Index(['pandas', 'NumPy', 'matplotlib'], dtype='str')
```

읽는 규칙 :
- **바깥 키**(`year`, `developer` ...) → **열 이름**
- **안쪽 키**(`pandas`, `NumPy` ...) → **행 이름(인덱스)**

> 💡 `name` 열이 비어 보이는 건 파일에 `"name": {"pandas": "", ...}` 처럼 **빈 글자**가 들어 있어서다.
> `opensource` 의 `True` 도 따옴표 안에 있는 **글자 "True"** 라서 진짜 True/False 가 아니다.

## 4. HTML(웹페이지) 표 읽기

웹페이지 안의 표는 `<table>` 이라는 태그로 만들어져 있다.
`read_html()` 은 페이지 안의 `<table>` 을 **전부** 찾아서 표로 바꿔 준다.

```python
url = './Data-Pandas/sample.html'

tables = pd.read_html(url)

print(len(tables))          # 2 → 표가 2개
print(type(tables))         # <class 'list'>
print(type(tables[0]))      # <class 'pandas.DataFrame'>
```

### 핵심 : 결과는 표 1개가 아니라 **표들이 담긴 리스트**

```
tables = [ 표0, 표1 ]
           ↑     ↑
     tables[0] tables[1]
```

표가 하나뿐이어도 리스트로 준다 → 꼭 `tables[0]` 처럼 **번호로 꺼내서** 써야 한다.

### 모든 표 출력하기

```python
for i in range(len(tables)):      # i = 0, 1
    print("tables[%s]" % i)       # %s 자리에 i 가 들어감 → "tables[0]"
    print(tables[i])
```

- `range(len(tables))` = `range(2)` = 0, 1
- `"tables[%s]" % i` = 옛날 방식 글자 끼워넣기. 요즘은 `f"tables[{i}]"` 를 더 많이 쓴다

### 원하는 표 꺼내서 인덱스 지정

```python
df = tables[1]
df.set_index(['name'], inplace=True)
print(df)
```

```
            year        developer  opensource
name
NumPy       2006  Travis Oliphant        True
matplotlib  2003   John D. Hunter        True
pandas      2008    Wes Mckinneye        True
```

> ⚠️ `read_html` 은 `lxml` 이라는 도구가 필요하다. 없으면 `ImportError` → `pip install lxml`
>
> 💡 `tables[0]` 에 생긴 `Unnamed: 0` 열 = HTML 표의 첫 칸(제목 칸)이 비어 있어서
> pandas 가 "이름 없음 0번" 이라고 붙인 이름이다.

## 5. 파일로 저장하기

### 5-1. 저장할 데이터 만들기

```python
data = {'name' : [ 'Jerry', 'Riah', 'Paul'],
        'algol' : [ "A", "A+", "B"],
        'basic' : [ "C", "B", "B+"],
        'c++' : [ "B+", "C", "C+"],
        }

df = pd.DataFrame(data)
df.set_index('name', inplace=True)   # name 열을 인덱스로 지정
```

```
      algol basic c++
name
Jerry     A     C  B+
Riah     A+     B   C
Paul      B    B+  C+
```

### 5-2. CSV / JSON 저장

```python
df.to_csv("./output/df_sample.csv")
df.to_json("./output/df_sample.json")
```

- `output` 폴더가 **미리 있어야** 한다. 없으면 `OSError` (폴더는 자동으로 안 만들어 줌)
- 인덱스(name)도 같이 저장된다. 인덱스를 빼고 싶으면 `to_csv(..., index=False)`
- 한글이 들어간 CSV 를 엑셀로 열 때 글자가 깨지면 → `to_csv(..., encoding='utf-8-sig')`

저장된 JSON 을 열어 보면 3장에서 읽었던 것과 같은 모양이다.

```json
{"algol":{"Jerry":"A","Riah":"A+","Paul":"B"}, "basic":{...}, "c++":{...}}
```

→ 바깥 키 = 열 이름, 안쪽 키 = 행 이름. **읽기와 저장은 서로 거꾸로**라는 걸 확인할 수 있다.

### 5-3. Excel 저장 — 🐞 버그 있음

```python
df.to_json("./output/df_sample.xlsx")   # ❌ 지금 코드
```

이름만 `.xlsx` 이고 **내용은 JSON 글자**다. 실제로 `output/df_sample.xlsx` 를 메모장으로 열면
`{"algol":{"Jerry":"A", ...` 가 들어 있다. 엑셀로 열면 "파일 형식이 잘못됐다" 고 나온다.

```python
df.to_excel("./output/df_sample.xlsx")  # ✅ 고친 코드
```

> 💡 **확장자(.xlsx)는 그냥 이름표일 뿐**, 파일 내용을 정하는 건 `to_` 뒤의 함수 이름이다.

### 5-4. 엑셀 파일 하나에 시트 여러 개 저장 — `ExcelWriter`

`to_excel("파일명")` 을 두 번 하면 **두 번째가 첫 번째를 덮어써서** 시트가 1개만 남는다.
표 여러 개를 한 파일의 다른 시트에 넣으려면 `ExcelWriter` 를 쓴다.

```python
df1 = pd.DataFrame(data1)               # 성적 표
df1.set_index('name', inplace=True)

df2 = pd.DataFrame(data2)               # 숫자 표
df2.set_index('c0', inplace=True)

writer = pd.ExcelWriter("./output/df_excelwriter.xlsx")   # ① 엑셀 파일 열기
df1.to_excel(writer, sheet_name="sheet1")                  # ② sheet1 에 df1 쓰기
df2.to_excel(writer, sheet_name="sheet2")                  # ③ sheet2 에 df2 쓰기
writer.close()                                             # ④ 저장하고 닫기
```

비유하면 **공책(writer)을 펴고 → 1쪽에 쓰고 → 2쪽에 쓰고 → 덮는 것**.
④ `close()` 를 안 하면 공책을 안 덮은 상태라 **파일이 저장되지 않거나 깨진다.**

더 안전한 방법 (`with` 문) — 블록이 끝나면 **자동으로 close** 해 준다.

```python
with pd.ExcelWriter("./output/df_excelwriter.xlsx") as writer:
    df1.to_excel(writer, sheet_name="sheet1")
    df2.to_excel(writer, sheet_name="sheet2")
```

> 🔍 **코드 리뷰** : 마크다운 제목 오타 `* toi excewriter` → `* to ExcelWriter`,
> `* ettxnsions -> browser` → `* extensions -> browser`

## 6. 읽어 온 데이터 살펴보기 (auto-mpg 자동차 데이터)

자동차 398대의 연비, 실린더 수, 무게 같은 정보가 담긴 파일이다.

### 6-1. 열 이름 붙여서 읽기

```python
df = pd.read_csv('./Data-Pandas/auto-mpg.csv', header=None)
df.columns = ['mpg','cylinders','displacement','horsepower','weight',
              'acceleration','model year','origin','name']
```

이 파일은 **첫 줄부터 바로 데이터**라서 (`18.0,8,307.0,130.0,...`) 열 이름 줄이 없다.
그래서 `header=None` 으로 읽고, `df.columns = [...]` 로 이름을 **직접 붙여** 준다.

| 열 | 뜻 |
|---|---|
| mpg | 연비 (1갤런으로 몇 마일 가는지, 클수록 좋음) |
| cylinders | 실린더(엔진 통) 개수 |
| displacement | 배기량 |
| horsepower | 마력 |
| weight | 무게 |
| acceleration | 가속 성능 |
| model year | 출시 연도 (70 = 1970년) |
| origin | 생산 지역 (1 = 미국, 2 = 유럽, 3 = 일본) |
| name | 자동차 이름 |

### 6-2. 살펴보기 도구 모음

| 코드 | 알려 주는 것 | 비유 |
|---|---|---|
| `df.head()` | 앞 5행 | 책 첫 페이지 훑기 |
| `df.tail()` | 뒤 5행 | 책 마지막 페이지 훑기 |
| `df.shape` | (행 수, 열 수) | 책 두께 |
| `df.dtypes` | 열마다 자료형 | 각 칸에 숫자가 들었나 글자가 들었나 |
| `df.info()` | 위 정보 + 빈칸 개수 한 번에 | 책 목차 |
| `df.describe()` | 숫자 열의 통계 요약 | 성적표 요약 |
| `df.count()` | 열마다 빈칸 아닌 값 개수 | 출석 인원 |
| `df['열'].value_counts()` | 값마다 몇 번 나왔는지 | 투표 개표 |

> ⚠️ `shape` 와 `dtypes` 는 **괄호 없음** (그냥 정보), `head()`, `info()` 는 **괄호 있음** (동작)

### 6-3. `shape` — 크기

```python
print(df.shape)   # (398, 9) → 398행, 9열
```

### 6-4. `dtypes` — 자료형, 그리고 수상한 `horsepower`

```
mpg             float64    ← 소수
cylinders         int64    ← 정수
horsepower          str    ← ❗ 글자?
name                str    ← 자동차 이름이니 글자가 맞음
```

마력은 숫자여야 하는데 **글자(str)** 로 나온다. 왜일까?
파일을 뒤져 보면 마력 칸 몇 군데에 숫자 대신 **`?`** 가 들어 있다 (6곳).
한 칸이라도 글자가 섞이면 pandas 는 **그 열 전체를 글자로** 읽는다.

그래서 :
- `describe()` 결과에 **horsepower 가 빠진다** (숫자 열만 계산하니까)
- `df['horsepower'] + 1` 같은 계산이 안 된다

> 🔜 다음에 배울 "데이터 전처리" 에서 `?` 를 NaN 으로 바꾸고 숫자로 변환하는 법을 배운다.
> 미리 보기 : `pd.read_csv(..., na_values='?')` 로 읽으면 `?` 가 처음부터 NaN 이 된다.

### 6-5. `info()` — 목차 보기

```
RangeIndex: 398 entries, 0 to 397     ← 행 398개, 인덱스 0~397
 #   Column        Non-Null Count  Dtype
 0   mpg           398 non-null    float64
 3   horsepower    398 non-null    str
...
```

- `Non-Null Count` = **빈칸이 아닌 값 개수**. 전부 398 이면 빈칸 없음
- `?` 는 빈칸이 아니라 "물음표라는 글자" 라서 **빈칸으로 안 센다** → 398 로 나옴 (함정!)

> 💡 `print(df.info())` 를 하면 결과 끝에 `None` 이 한 줄 더 찍힌다.
> `info()` 는 스스로 화면에 출력하고 아무것도 돌려주지 않기(None) 때문. 그냥 `df.info()` 만 쓰면 된다.

### 6-6. `describe()` — 통계 요약

### 6-7. `describe(include='all')` — 글자 열도 포함

```python
print(df.describe(include='all'))
```

글자 열(horsepower, name)은 평균을 낼 수 없으니 다른 정보가 나온다.

| 항목 | 뜻 | horsepower 결과 |
|---|---|---|
| unique | 서로 다른 값이 몇 종류인지 | 94 종류 |
| top | 가장 많이 나온 값 | '150.0' |
| freq | top 이 나온 횟수 | 22 번 |

숫자 열에는 unique/top/freq 가 NaN, 글자 열에는 mean/std 가 NaN 으로 나온다.
("해당 없음" 이라는 뜻)

### 6-8. `count()` — 열마다 값 개수

```python
print(df.count())          # 모든 열 398
print(type(df.count()))    # <class 'pandas.Series'>
```

결과가 **시리즈** → 인덱스 = 열 이름, 값 = 개수

### 6-9. `value_counts()` — 값마다 개수 세기

```python
unique_values = df['origin'].value_counts()
print(unique_values)
```

```
origin
1    249     ← 미국 차 249대
3     79     ← 일본 차 79대
2     70     ← 유럽 차 70대
```

- **많은 순서**로 자동 정렬된다
- 원래 의미는 "값별 개수 세기" 다. 변수 이름 `unique_values` 보다 `origin_counts` 가 더 정확하다
- 고유값 **목록**만 보고 싶으면 `df['origin'].unique()` → `[1, 3, 2]`

## 9. 한눈에 요약

1. 읽기 = `pd.read_csv / read_excel / read_json / read_html`, 저장 = `df.to_csv / to_excel / to_json`
2. `header=0` (기본) = 첫 줄이 열 이름 / `header=None` = 열 이름 줄 없음 → 0, 1, 2 ... 자동
3. `index_col='열'` = 읽으면서 그 열을 행 인덱스로
4. JSON : 바깥 키 → 열, 안쪽 키 → 행
5. `read_html` 은 **표들의 리스트** → `tables[0]` 으로 꺼내기
6. 파일 내용은 **함수**가 정한다. 확장자는 이름표일 뿐 (`to_json` + `.xlsx` = 가짜 엑셀)
7. 시트 여러 개 = `ExcelWriter` + `sheet_name`, 끝나면 `close()` (또는 `with`)
8. 처음 보는 데이터는 `head → shape → info → describe → value_counts` 순서로 훑어보기
9. 숫자 열이 `str` 로 나오면 **이상한 글자(`?` 등)가 섞여 있다**는 신호
