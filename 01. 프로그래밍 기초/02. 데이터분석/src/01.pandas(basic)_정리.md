# pandas 기초 정리 (01.pandas(basic).ipynb)

> pandas = 파이썬에서 **표(엑셀 같은 데이터)** 를 다루는 라이브러리
> 항상 `import pandas as pd` 로 불러오고, `pd.` 으로 사용한다.

---

## 1. 큰 그림: Series vs DataFrame

| 구분 | Series (시리즈) | DataFrame (데이터프레임) |
|---|---|---|
| 모양 | **1차원** (한 줄짜리 목록) | **2차원** (행 × 열의 표) |
| 비유 | 엑셀의 **열 하나** | 엑셀의 **시트 전체** |
| 구성 | 인덱스 + 값 | 행 인덱스 + 열 이름 + 값 |
| 만들기 | `pd.Series(...)` | `pd.DataFrame(...)` |

```
Series                 DataFrame
인덱스  값              (열 이름) 수학  영어
  a     1             서준       90    98
  b     2             우현       80    89
  c     3             인아       70    95
                      ↑ 행 인덱스
```

> 💡 DataFrame 에서 **행 하나 또는 열 하나만 꺼내면 → Series** 가 된다.

---

## 2. Series 만들기

### 2-1. 딕셔너리 → 시리즈
```python
sr = pd.Series({'a': 1, 'b': 2, 'c': 3})
```
- **키 → 인덱스**, **값 → 데이터**

### 2-2. 리스트 → 시리즈
```python
sr = pd.Series(['2019-01-02', 3.14, 'ABC', 100, True])
```
- 키가 없으므로 인덱스가 **0, 1, 2, ... 자동 생성**
- 자료형이 섞여 있으면 `dtype: object` 로 표시됨

### 2-3. 튜플 → 시리즈 (인덱스 직접 지정)
```python
sr = pd.Series(('영인', '2010-05-01', '여', True),
               index=['이름', '생년월일', '성별', '학생여부'])
```
- `index=[...]` 로 이름표를 붙일 수 있다 (**개수가 데이터와 같아야 함**)

### 2-4. 인덱스 / 값 따로 꺼내기
| 코드 | 결과 |
|---|---|
| `sr.index` | 인덱스만 (예: `RangeIndex(start=0, stop=5, step=1)`) |
| `sr.values` | 값만 (numpy 배열) |

---

## 3. Series 원소 선택

| 목적 | 코드 | 설명 |
|---|---|---|
| 1개 (위치) | `sr.iloc[0]` | 0번째 원소 |
| 1개 (이름) | `sr['이름']` | 인덱스 이름으로 |
| 여러 개 (위치 슬라이싱) | `sr.iloc[1:3]` | 1, 2번 (**3은 미포함**) |
| 여러 개 (이름 목록) | `sr[['생년월일', '성별']]` | **대괄호 2겹** |

> 💡 **대괄호 2겹 `[[ ]]` 의 의미**
> 바깥 `[ ]` = "선택할게" 문법, 안쪽 `[ ]` = "이 목록(리스트)을" → 여러 개 선택할 때 사용

---

## 4. DataFrame 만들기

### 4-1. 딕셔너리 → 데이터프레임
```python
df = pd.DataFrame({'c0': [1, 2, 3], 'c1': [4, 5, 6]})
```
- **키 → 열 이름**, **리스트 → 그 열의 데이터 (위→아래)**

### 4-2. 2차원 리스트 → 데이터프레임
```python
df = pd.DataFrame([[15, '남', '덕영중'],
                   [17, '여', '수리중']],
                  index=['준서', '예은'],          # 행 이름
                  columns=['나이', '성별', '학교'])  # 열 이름
```
- **안쪽 리스트 하나 = 행 하나**
- `df.index` → 행 이름, `df.columns` → 열 이름

> ⚠️ 딕셔너리는 "열 단위", 2차원 리스트는 "행 단위"로 데이터가 들어간다는 점이 다르다!

---

## 5. 이름 바꾸기 `rename()`

```python
df.rename(columns={'나이': '연령'}, inplace=True)  # 열 이름 변경
df = df.rename(index={'준서': '학생1'})            # 행 이름 변경
```
- `{기존이름: 새이름}` 딕셔너리로 전달
- `columns=` → 열, `index=` → 행

---

## 6. ⭐ `inplace` 옵션 (매우 중요)

pandas 함수 대부분(`rename`, `drop` 등)은 **원본을 바꾸지 않고 새 결과를 돌려준다.**

| 방식 | 코드 | 원본 df |
|---|---|---|
| inplace=True | `df.drop('우현', inplace=True)` | **바로 바뀜** (반환값 없음) |
| 다시 대입 | `df = df.drop('우현')` | 새 결과로 **덮어씀** |
| 둘 다 안 함 | `df.drop('우현')` | ❌ **아무 변화 없음** (자주 하는 실수!) |

> ⚠️ `df = df.drop('우현', inplace=True)` 처럼 **둘을 같이 쓰면 df 가 `None` 이 되어버린다!** 둘 중 하나만 쓰자.

---

## 7. 삭제하기 `drop()` 과 `axis`

```python
df.drop('우현', inplace=True)                      # 행 1개 삭제
df.drop(['우현', '인아'], axis=0, inplace=True)     # 행 여러 개 삭제
df.drop('수학', axis=1, inplace=True)               # 열 1개 삭제
df.drop(['영어', '음악'], axis=1, inplace=True)      # 열 여러 개 삭제
```

| axis | 의미 | 비고 |
|---|---|---|
| `axis=0` | **행(row)** 방향 | 기본값 → 생략 가능 |
| `axis=1` | **열(column)** 방향 | 열 지울 땐 꼭 써야 함 |

> 💡 외우는 팁: **0 = 행(가로줄), 1 = 열(세로줄)**
> (최신 방식: `df.drop(columns='수학')`, `df.drop(index='우현')` 처럼 써도 된다)

---

## 8. 복사하기: `df[:]` vs `df.copy()`

```python
df2 = df[:]        # 전체 슬라이싱
df4 = df.copy()    # 복사본 생성 ← 권장
df_x = df          # ❌ 복사 아님! 같은 표에 이름만 하나 더 붙임
```
- `df_x = df` 는 **같은 객체**를 가리키므로 df_x 를 수정하면 df 도 바뀐다.
- 원본을 지키면서 실습하려면 **`df.copy()`** 를 쓰는 것이 가장 안전하다.

## 9. ⭐ 행 선택: `loc` vs `iloc` (가장 중요)

| | `loc` | `iloc` |
|---|---|---|
| 뜻 | **loc**ation | **i**nteger **loc**ation |
| 기준 | **이름(라벨)** | **위치 번호 (0부터)** |
| 1개 | `df.loc['서준']` | `df.iloc[0]` |
| 여러 개 | `df.loc[['서준', '우현']]` | `df.iloc[[0, 1]]` |
| 슬라이싱 | `df.loc['서준':'우현']` | `df.iloc[0:2]` |
| 슬라이싱 끝 | ✅ **포함** | ❌ **미포함** |

> ⚠️ **슬라이싱 끝 포함 여부가 다르다!**
> - `df.loc['서준':'우현']` → 서준, 우현 (끝 '우현' 포함)
> - `df.iloc[0:2]` → 0번, 1번 (끝 2번 미포함, 파이썬 기본 슬라이싱과 같음)

### 결과 형태
- 행 **1개** 선택 → **Series** (세로로 출력, 열 이름이 인덱스가 됨)
- 행 **2개 이상** 선택 → **DataFrame** (표로 출력)

## ✅ 한눈에 요약

1. **Series = 1차원**, **DataFrame = 2차원 표**
2. 딕셔너리 키 → Series는 **인덱스**, DataFrame은 **열 이름**
3. 여러 개 선택할 땐 **대괄호 2겹 `[[ ]]`**
4. `inplace=True` 를 쓰거나 **`df = ...` 로 다시 대입**해야 변경이 남는다 (둘 중 하나만!)
5. `axis=0` **행** / `axis=1` **열**
6. `loc` = **이름**, `iloc` = **번호** / 슬라이싱 시 **loc는 끝 포함, iloc는 끝 미포함**
7. 원본 보존용 복사는 **`df.copy()`**
