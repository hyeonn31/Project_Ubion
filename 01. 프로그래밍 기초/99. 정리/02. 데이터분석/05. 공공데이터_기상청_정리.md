### `encoding='cp949'` 를 안 쓰면

```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xb3 in position 0: invalid start byte
```

**인코딩** = 글자를 파일에 저장하는 방식. 같은 한글도 방식에 따라 다른 숫자로 저장된다.
저장한 방식과 읽는 방식이 다르면 글자를 해석하지 못해 에러가 난다.
`read_csv` 는 따로 말해 주지 않으면 UTF-8 로 읽는데, 이 파일은 CP949 로 저장돼 있다.

| 인코딩 | 주로 쓰이는 곳 |
|---|---|
| `utf-8` | 웹, 리눅스, 맥에서 만든 데이터. **`read_csv` 의 기본값** |
| `utf-8-sig` | UTF-8 + BOM. 엑셀에서 UTF-8 로 저장한 파일 |
| `cp949` | **윈도우 엑셀**에서 작업한 한글 데이터 |
| `euc-kr` | 오래된 사이트, 일부 공공기관 파일 (cp949 와 거의 같다) |
| `utf-16` | 2바이트 기반 유니코드 (엑셀의 "유니코드 텍스트") |
| `latin1` (iso-8859-1) | 서유럽 문자용 |

> 💡 한글 CSV 에서 `UnicodeDecodeError` 가 나면 **`encoding='cp949'` 부터** 넣어 본다.
> 반대로 cp949 로 읽었는데 에러가 나면 `utf-8` 이다. 공공기관 자료는 cp949 인 경우가 많다.
>
> 🔍 **코드 리뷰** : 노트북의 메모에 `utf=16` 으로 적혀 있다. `utf-16` 의 오타.

### 2-2. `iterrows()` — 표를 한 줄씩 꺼내기

```python
count = 0
for index, row in df.iterrows():
    count += 1
    # print(index, row, type(row))

```

`df.iterrows()` 는 표를 **위에서부터 한 줄씩** 넘겨준다. 한 번 돌 때마다 값 2개를 준다.

| 변수 | 들어 있는 것 | 첫 줄에서의 값 |
|---|---|---|
| `index` | 그 줄의 행 이름표 | `0` |
| `row` | 그 줄 전체 (**시리즈**) | 날짜, 지점, 평균·최저·최고기온 |

`row['최고기온(℃)']` 처럼 열 이름으로 그 줄의 값을 꺼낼 수 있다.
여기서는 줄 수만 세었고(`count += 1` = count 를 1 늘린다), 결과는 `len(df)` 와 같은 40222 다.

> 💡 `iterrows()` 는 이해하기 쉽지만 **느리다.** 줄이 많으면 pandas 의 열 단위 계산(`max()`, `idxmax()`, `mask`)이 훨씬 빠르다.
> "한 줄씩 직접 확인해 보고 싶을 때" 쓰는 도구로 기억한다.

## 3. 서울의 최고기온이 가장 높았던 날은?

**답 : 2018년 8월 1일, 39.6℃**

같은 문제를 두 가지 방법으로 풀었다.

### 3-1. for 문으로 — 하나씩 비교하며 기록 갱신

```python
high = -999        # 지금까지의 최고 기온 (아주 낮은 값에서 시작)
high_date = ''     # 그 기온이 나온 날짜

for i in range(len(df)):               # i = 0, 1, 2, ..., 40221 (줄 번호)
    temp = df.iloc[i, 4]               # i 번째 줄의 4번 열(최고기온) 꺼내기
    if pd.notnull(temp):               # 빈칸이 아닐 때만
        if temp > high:                # 지금까지의 기록보다 높으면
            high = temp                # 기록 갱신
            high_date = df.loc[i, '날짜']   # 날짜도 함께 기억

print(high_date, high)   # 2018-08-01 39.6
```

운동회에서 "지금까지 제일 멀리 던진 사람" 을 칠판에 적어 두고, 더 멀리 던진 사람이 나오면 지우고 다시 쓰는 것과 같다.

| 줄 | 왜 이렇게 쓰나 |
|---|---|
| `high = -999` | 시작값. **for 문 밖**에 한 번만 쓴다. 안에 쓰면 돌 때마다 기록이 지워진다 |
| `-999` | 기온은 영하일 수 있다. 0 에서 시작하면 전부 영하인 데이터에서 한 번도 갱신되지 않는다 |
| `range(len(df))` | `len(df)` 는 숫자 40222 하나. `range()` 로 0 ~ 40221 을 만들어야 for 가 돌 수 있다 |
| `df.iloc[i, 4]` | i 번째 줄, 4번 열(0부터 세어 다섯 번째 = 최고기온) |
| `pd.notnull(temp)` | 빈칸(NaN)이 아니면 True. 빈칸은 건너뛴다 |

> 💡 `pd.notnull()` 이 없어도 답은 같다. NaN 은 어떤 값과 비교해도 False 라서 `temp > high` 를 통과하지 못한다.
> 그래도 "빈칸은 건너뛴다" 는 뜻이 코드에 드러나서 읽기 좋다.

## 4. 날짜 다듬기

```python
df['날짜'] = pd.to_datetime(df['날짜'].astype(str).str.strip())
```

**지저분한 글자를 진짜 날짜로 바꿔서 다시 저장**하는 줄이다. 안쪽부터 실행된다.

| 순서 | 부분 | 하는 일 | 값의 변화 |
|---|---|---|---|
| ① | `df['날짜']` | 날짜 열을 꺼낸다 | `'\t1907-10-01'` |
| ② | `.astype(str)` | 무엇이든 일단 글자로 바꾼다 | `'\t1907-10-01'` |
| ③ | `.str.strip()` | 글자 앞뒤의 공백 · 탭을 뗀다 | `'1907-10-01'` (아직 글자) |
| ④ | `pd.to_datetime(...)` | 글자를 진짜 날짜로 바꾼다 | `1907-10-01` (날짜) |
| ⑤ | `df['날짜'] = ...` | 결과를 날짜 열에 덮어쓴다 | |

### 글자 날짜와 진짜 날짜

- **글자일 때** : 컴퓨터에게는 `2`, `0`, `1`, `8`, `-` ... 가 나열된 낙서다. "몇 월이야?" 에 대답하지 못한다.
- **진짜 날짜일 때** : "2018년 8월 1일" 로 이해한다. 월만 꺼내거나 날짜끼리 비교할 수 있다.

`pd.to_datetime()` 이 이 "이해시키기" 를 한다. 숫자로 바꾸던 `pd.to_numeric()` 의 형제 함수다.

### `.str` 과 `.dt`

| 통로 | 쓸 수 있는 열 | 뜻 | 예 |
|---|---|---|---|
| `.str` | **글자** 열 | 모든 칸에 글자 기능 적용 | `.str.strip()`, `.str.replace()` |
| `.dt` | **날짜** 열 | 모든 칸에 날짜 기능 적용 | `.dt.year`, `.dt.month`, `.dt.day` |

### `.astype(str)` 을 넣는 이유 — 내가 만난 에러

처음에는 이렇게 썼다.

```python
df['날짜'] = pd.to_datetime(df['날짜'].str.strip())
```

한 번은 잘 되지만, **같은 셀을 다시 실행하면** 에러가 난다.

```
AttributeError: Can only use .str accessor with string values, not datetime64
```

| 실행 | `날짜` 열 | 결과 |
|---|---|---|
| 1번째 | 글자 | `.str.strip()` 성공 → 날짜로 변환 |
| 2번째 | **이미 날짜** | 날짜에는 `.str` 을 쓸 수 없다 → 에러 |

`.astype(str)` 을 넣으면 "지금 무엇이든 일단 글자로" 되돌린 뒤 시작하므로 **몇 번을 실행해도** 괜찮다.

> 💡 더 좋은 방법은 **`read_csv` 바로 아래에서 한 번만** 변환해 두는 것이다. 그러면 그래프 셀마다 이 줄을 넣지 않아도 된다.

### 바꾼 뒤 확인

```python
print(df['날짜'].dtype)   # datetime64[us]  ← datetime64 로 시작하면 날짜
```

맨 마지막 빈 줄(`'\t'`)은 날짜로 바꿀 것이 없어서 `NaT`(날짜의 빈칸)가 된다. 에러는 나지 않는다.

## 5. 내 생일의 기온 그래프

### 5-1. 매년 내 생일인 줄만 고르기

```python
month = 8
day = 31

mask = (df['날짜'].dt.month == month) & (df['날짜'].dt.day == day)
df_birth = df[mask]
```

`.dt.month` 는 날짜마다 **월만** 꺼낸 숫자 목록, `.dt.day` 는 **일만** 꺼낸 숫자 목록이다.

| 날짜 | `.dt.month == 8` | `.dt.day == 31` | `&` (둘 다 True?) |
|---|---|---|---|
| 2018-08-30 | True | False | False |
| **2018-08-31** | True | True | **True** |
| 2018-09-01 | False | False | False |
| 2018-10-31 | False | True | False |

- `&` = 그리고. 두 조건이 **모두** True 인 줄만 남는다. 조건마다 괄호 `( )` 로 감싸야 한다.
- `df[mask]` = mask 가 True 인 줄만 고른다. 결과는 **109줄** (1908 ~ 2018년, 매년 8월 31일).
- 1951년, 1952년은 그날의 줄이 아예 없고, 1953년은 줄은 있지만 기온이 비어 있다.

### 5-2. 평균기온 선 그래프

```python
import matplotlib.pyplot as plt
from matplotlib import font_manager, rc

# 한글 글꼴 설정 (그래프의 한글이 깨지지 않게)
font_name = font_manager.FontProperties(fname='./Data-Pandas/malgun.ttf').get_name()
rc('font', family=font_name)
plt.rcParams['axes.unicode_minus'] = False   # 마이너스(-) 부호 깨짐 방지

plt.figure()
plt.plot(df_birth['날짜'].dt.year, df_birth['평균기온(℃)'], marker='+', markersize=4, color='tomato')

plt.title(f'내 생일({month}월 {day}일)의 평균기온 변화', size=20)
plt.xlabel('연도', size=12)
plt.ylabel('평균기온(℃)', size=12)
plt.show()
```

| 부분 | 뜻 |
|---|---|
| `plt.plot(x, y)` | x = 연도(`.dt.year`), y = 그날의 평균기온 |
| `marker='+'` | 값이 있는 자리마다 + 모양 표시 |
| `color='tomato'` | 선 색 |
| `f'내 생일({month}월 {day}일)...'` | **f-문자열**. `{ }` 안에 변수 값이 들어간다 → `내 생일(8월 31일)...` |

**결과 읽기** : 8월 31일의 평균기온은 110여 년 동안 17.7 ~ 28.2℃ 사이를 오갔고, 평균은 23.5℃ 다.
1950 ~ 1954년 사이에서 선이 끊긴다. 값이 없는 해(1953년)가 있어서다.

> 💡 **f-문자열** 은 글자 앞에 `f` 를 붙이고 `{변수}` 를 쓰는 방식이다.
> `month`, `day` 만 바꾸면 제목도 함께 바뀌므로, 날짜를 바꿔 가며 그리기 편하다.

### 5-3. 최고기온(빨강) · 최저기온(파랑) 함께 그리기

```python
# 결측치(빈칸) 제거 : 두 열 중 하나라도 비어 있는 줄을 지운다
df = df.dropna(subset=['최고기온(℃)'])
df = df.dropna(subset=['최저기온(℃)'])

# 기온 숫자 변환. errors='coerce' : 바꿀 수 없는 값은 NaN 으로
df['최고기온(℃)'] = pd.to_numeric(df['최고기온(℃)'], errors='coerce')
df['최저기온(℃)'] = pd.to_numeric(df['최저기온(℃)'], errors='coerce')

# 매년 내 생일인 행만 고르기
mask = (df['날짜'].dt.month == month) & (df['날짜'].dt.day == day)
df_birth = df[mask]

# 선 그래프 : 같은 도화지에 plot 을 두 번 → 선 2개
plt.figure(figsize=(14, 5))
plt.plot(df_birth['날짜'].dt.year, df_birth['최고기온(℃)'], color='red', label='최고기온')
plt.plot(df_birth['날짜'].dt.year, df_birth['최저기온(℃)'], color='blue', label='최저기온')

plt.title(f'내 생일({month}월 {day}일)의 최고기온 · 최저기온 변화', size=20)
plt.xlabel('연도', size=12)
plt.ylabel('기온(℃)', size=12)
plt.legend(loc='best')   # 각 plot 의 label 을 모아 범례로 표시
plt.show()
```

**선을 두 개 그리는 법** : 같은 도화지에 `plt.plot()` 을 **두 번** 쓴다. 한 번에 선 하나씩 겹쳐 그려진다.

| 옵션 | 뜻 |
|---|---|
| `color='red'` / `'blue'` | 선 색 |
| `label='최고기온'` | 범례에 표시할 이름 |
| `plt.legend(loc='best')` | 범례를 띄운다. `label` 만 쓰고 이 줄을 빼면 범례가 안 나온다 |

**결과 읽기** (8월 31일, 108개 해)

| | 가장 낮았던 해 | 가장 높았던 해 | 평균 |
|---|---|---|---|
| 최고기온 | 19.2℃ | 34.5℃ (1922년) | 28.2℃ |
| 최저기온 | 14.4℃ (1913년) | 25.4℃ | 19.9℃ |

빨간 선이 항상 파란 선 위에 있다. 같은 날의 최고기온이 최저기온보다 높으니 당연한 결과이고, 데이터를 제대로 골랐다는 확인이기도 하다.

### `dropna()` — 빈칸이 있는 줄 지우기

```python
df = df.dropna(subset=['최고기온(℃)'])
```

- `dropna()` = NaN 이 있는 **줄을 통째로** 지운다.
- `subset=[...]` = "이 열이 비어 있을 때만" 지운다. 안 쓰면 어느 열이든 하나라도 비면 지운다.
- 원본을 바꾸지 않으므로 `df = ...` 로 다시 저장한다.
- 두 줄을 한 번에 쓸 수 있다 : `df = df.dropna(subset=['최고기온(℃)', '최저기온(℃)'])`

## 6. 코드 리뷰 — 알고 넘어갈 점

### 6-1. `dropna` 를 하면 그래프의 "끊긴 곳" 이 이어진다

| | 5-2 의 그래프 (dropna 안 함) | 5-3 의 그래프 (dropna 함) |
|---|---|---|
| 1953년 | 값이 NaN → **선이 끊긴다** | 줄이 지워짐 → 1950년과 1954년이 **직선으로 이어진다** |

끊긴 선은 "여기는 기록이 없다" 는 것을 보여 준다. 이어진 선은 그 사이에도 값이 있었던 것처럼 보인다.
**빈칸을 지우면 그래프가 깔끔해지지만, 없는 기록을 있는 것처럼 보이게 할 수 있다**는 점을 기억한다.

### 6-2. `df = df.dropna(...)` 는 `df` 자체를 바꾼다

5-3 의 셀을 실행하면 `df` 가 40,222줄에서 39,463줄로 **줄어든 채 남는다.** 그 뒤에 위쪽 셀을 다시 실행하면 문제가 생긴다.

직접 해 보면, 3-1 의 for 문이 **에러 없이 틀린 답**을 낸다.

| | 결과 |
|---|---|
| 원래 `df` 로 실행 | 2018-08-01, 39.6℃ ✅ |
| `dropna` 한 `df` 로 실행 | **2016-07-04**, 39.6℃ ❌ (기온은 맞고 날짜가 틀림) |

에러가 나면 바로 알아차리지만, 이렇게 조용히 틀리면 알아차리기 어렵다. 원인은 바로 아래 6-3 이다.

**해결** : 원본은 그대로 두고 새 이름에 담는다.

```python
df_clean = df.dropna(subset=['최고기온(℃)', '최저기온(℃)'])
```

이미 `df` 가 줄어들었다면 `read_csv` 셀부터 다시 실행한다.

### 6-3. `iloc` 과 `loc` 을 섞어 쓴 for 문

```python
temp = df.iloc[i, 4]            # i = "몇 번째 줄" (위치)
high_date = df.loc[i, '날짜']    # i = "이름표가 i 인 줄" (이름)
```

처음에는 이름표가 0, 1, 2 ... 라서 위치와 이름이 같아 문제가 없다.
하지만 `dropna` 로 줄이 지워지면 이름표에 빈 번호가 생겨서 **둘이 서로 다른 줄을 가리킨다.**
기온은 "i 번째 줄" 에서, 날짜는 "이름표가 i 인 줄" 에서 가져오게 되어 6-2 처럼 날짜만 틀린다.
한 가지로 통일하면 `df` 가 어떻게 바뀌든 맞는 답이 나온다.

```python
temp = df.iloc[i, 4]
high_date = df.iloc[i, 0]       # 둘 다 위치로
```

### 6-4. 이 데이터에서는 `pd.to_numeric()` 이 필요 없다

`info()` 에서 봤듯이 기온 열은 이미 `float64`(숫자)다. 그래서 `pd.to_numeric()` 은 아무것도 바꾸지 않는다. 해롭지는 않다.

숫자로 바꿔야 하는 데이터라면 **순서**가 중요하다. `errors='coerce'` 는 바꿀 수 없는 값을 NaN 으로 만들기 때문에,
**① 숫자 변환 → ② `dropna`** 순서여야 새로 생긴 NaN 까지 지워진다. 노트북은 반대 순서다.

### 6-5. 제목과 내용 맞추기

마크다운 제목은 "내 생일의 평균 기온데이터를 라인그래프로 그리기(최고기온)" 인데, 코드는 평균기온을 그린다.
제목을 "내 생일의 평균기온을 라인그래프로 그리기" 로 고치면 헷갈리지 않는다.

## 7. 만날 수 있는 에러

| 에러 | 원인 | 해결 |
|---|---|---|
| `UnicodeDecodeError: 'utf-8' codec can't decode ...` | 파일이 cp949 인데 utf-8 로 읽음 | `encoding='cp949'` |
| `TypeError: int() argument must be ... not 'DataFrame'` | `int(df)` — 표 전체를 숫자 하나로 바꾸려 함 | `len(df)` 만 쓴다 |
| `TypeError: 'int' object is not iterable` | `for i in len(df):` — 숫자 하나는 돌 수 없음 | `range(len(df))` |
| `ValueError: Length mismatch: Expected axis has 40222 elements, new values have 2` | `df.index = [이름 2개]` — 행 수와 개수가 다름 | 열을 고르려던 것이면 `df[['a', 'b']]` |
| `AttributeError: Can only use .str accessor with string values` | 이미 날짜로 바꾼 열에 `.str` 을 또 씀 (셀을 두 번 실행) | `.astype(str).str.strip()` |
| `AttributeError: Can only use .dt accessor with datetimelike values` | 글자인 열에 `.dt` 를 씀 | `pd.to_datetime()` 먼저 |
| `KeyError: '최고기온'` | 열 이름이 다름 | `'최고기온(℃)'` 처럼 괄호까지 똑같이 |
| 그래프의 한글이 □□□ | 한글 글꼴 설정을 안 함 | `rc('font', family=font_name)` |

## 8. 한눈에 요약

1. 한글 CSV 가 안 읽히면 **`encoding='cp949'`**. 공공기관 자료는 cp949 가 많다
2. 처음 보는 데이터는 `head()`, **`tail()`**, `shape`, `info()` 로 훑는다. 마지막 줄과 빈칸 수를 꼭 본다
3. `df.iterrows()` = 표를 한 줄씩 꺼내기 (`index`, `row`). 이해하기 쉽지만 느리다
4. 최댓값 찾기 : `max()` = 값, **`idxmax()`** = 그 값이 있는 줄 번호, `df.loc[줄 번호]` = 그 줄 전체
5. for 문으로 최댓값을 찾을 때 시작값은 **for 밖**에, 그리고 충분히 작은 값으로
6. 날짜는 **`pd.to_datetime()`** 으로 바꿔야 `.dt.year` / `.dt.month` / `.dt.day` 를 쓸 수 있다
7. `.str` 은 글자 열 전용, `.dt` 는 날짜 열 전용. 순서는 `.str.strip()` → `pd.to_datetime()` → `.dt`
8. 같은 날짜만 고르기 : `(df['날짜'].dt.month == 월) & (df['날짜'].dt.day == 일)`
9. 선 여러 개 = `plt.plot()` 을 여러 번 + 선마다 `label` + `plt.legend()`
10. `dropna()` 는 그래프의 빈 구간을 이어 버린다. 그리고 `df = df.dropna()` 는 **원본을 바꾸니** 새 이름에 담는다
