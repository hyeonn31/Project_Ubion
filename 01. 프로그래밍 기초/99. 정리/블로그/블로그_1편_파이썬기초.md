## 2. 1주차에 배운 파이썬 문법

1주차는 파이썬 문법을 처음부터 차근차근 배웠습니다.

- **자료형** : 숫자형, 문자형, 리스트·튜플·딕셔너리·집합 같은 컬렉션
- **제어문** : if / for / while, enumerate 함수
- **함수와 파일 입출력** : 함수 정의, 매개변수와 반환값, 파일 읽고 쓰기
- **클래스** : 가상 계좌 만들기, 상속, 메서드 오버라이딩, 클래스 변수와 인스턴스 속성
- **예외처리** : try / except, 오류 일부러 발생시키기, 나만의 예외 만들기
- **모듈** : 내가 만든 .py 파일을 import 해서 쓰기

딕셔너리의 `keys()`, `values()`는 처음에 정말 헷갈렸는데, 수업이 끝나면 그날 배운 내용을 마크다운 문서로 다시 정리했더니 조금씩 머릿속에 자리 잡았어요.

특히 클래스 시간에 **가상 계좌**를 예제로 입금·출금 기능을 만들어 본 게 기억에 남습니다. 금융권 취업을 준비하는 입장에서 "은행 시스템도 결국 이런 구조로 만들어지겠구나" 하고 감이 왔거든요.

예외처리를 배운 뒤에는 자주 만나는 오류를 표로 따로 정리해 뒀습니다. `ValueError`(값이 잘못됨), `TypeError`(자료형이 잘못됨), `KeyError`(딕셔너리에 없는 키), `ZeroDivisionError`(0으로 나눔)처럼요. 에러 메시지를 읽는 법을 알고 나니 빨간 글씨가 떠도 덜 무서워졌어요. 😄

## 3. 첫 미니 프로젝트 : 영화관 예매 프로그램

문법을 배운 직후에 바로 **영화관 예매 프로그램**을 만들었습니다. 흐름은 이렇습니다.

1. 상영 중인 영화 목록을 보여주고 영화를 선택받기
2. 예매 인원 수 입력받기
3. 할인 쿠폰 코드 확인하기
4. 원래 금액, 할인 금액, 최종 결제 금액 출력하기

만들면서 제일 많이 배운 건 **"사용자는 내 예상대로 입력하지 않는다"**는 점이었어요.
인원 수에 `abc`나 `-1`, `0`을 넣으면 프로그램이 이상하게 동작하더라고요. 그래서 `while True` 반복문과 `isdigit()`으로 숫자인지 먼저 확인하고, 1명 이상일 때만 다음 단계로 넘어가도록 입력 검증을 넣었습니다.

쿠폰 코드는 사용자가 `orange`처럼 소문자로 입력하거나 앞뒤에 공백을 넣을 수도 있어서, `strip().upper()`로 정리한 뒤 딕셔너리에서 할인 금액을 찾도록 만들었어요. 금액은 `f'{price:,}원'`처럼 천 단위 콤마를 넣어서 보기 좋게 출력했고요.

단순해 보이는 콘솔 프로그램인데도 예외 상황을 하나하나 생각하다 보니 고민할 거리가 꽤 많았습니다. 개발자가 "입력값 검증"을 왜 그렇게 강조하는지 처음으로 체감한 순간이었어요.

## 4. 금융 알고리즘을 파이썬으로 풀어보기

금융권 취업이 목표다 보니 이 파트가 특히 재미있었습니다. 실제 투자에서 쓰는 계산을 파이썬 코드로 직접 구현해 봤어요.

- **수익률 등급 분류** : 매수가와 현재가로 수익률을 계산하고, 15% 이상은 A, 5% 이상은 B, 0% 이상은 C, 손실이면 D로 분류
- **목표 매도가** : 매수가 × (1 + 목표 수익률)
- **손익분기 매도가** : 매수가 ÷ (1 − 수수료율 − 세율)
- **월 복리 계산** : 연 수익률을 12로 나눠 월 수익률로 바꾸고, 반복문으로 24개월 동안 이자를 원금에 더하기

손익분기 매도가는 처음에 그냥 "매수가 + 수수료"라고 생각했는데, 수수료와 세금이 **매도 금액**에 붙는다는 걸 고려하면 나누기로 계산해야 한다는 걸 알게 됐어요. 막연하게 알던 금융 개념을 숫자로 정확하게 이해하게 된 게 가장 큰 수확이었습니다.
