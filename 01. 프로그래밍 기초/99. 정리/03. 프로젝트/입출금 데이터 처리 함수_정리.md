# 입출금 데이터 처리 함수 만들기

> 가계부 데이터를 **검증 → 열 추가 → 요약 → CSV 저장** 하는 함수를 하나씩 만든다.
> 나중에 Streamlit 앱에 그대로 붙여 쓰는 게 목표.

```
원본 → validate_records → add_features → summarize → csv_bytes
        (검증)            (월·표시 열)    (요약)       (CSV bytes)
```

---

## 함수 한눈에

| 함수 | 하는 일 | 핵심 |
|---|---|---|
| `empty_records()` | 빈 표 틀 만들기 | 0행이어도 컬럼·자료형은 유지 |
| `validate_records()` | 규칙 검사 + 정리 | 틀리면 `ValueError`로 멈춤 |
| `load_sample()` | data 폴더 CSV 읽기 | 읽자마자 검증 |
| `read_csv_bytes()` | 업로드된 bytes 읽기 | utf-8-sig → cp949 순서로 시도 |
| `add_features()` | 월, 표시 열 추가 | `apply(lambda, axis=1)` |
| `summarize()` | 항목별 / 월별 요약 | `groupby`, `pivot_table` |
| `csv_bytes()` | CSV bytes 만들기 | 수식 방지 `'`, 엑셀용 `utf-8-sig` |

---

## validate_records() : 핵심만

**검사 규칙**
- 필수 컬럼 4개 (날짜·구분·항목·금액), 최대 5,000행
- 날짜 `YYYY-MM-DD` + 실제 있는 날짜 + 1900~2100년
- 구분은 `수입` / `지출`, 항목은 1~40글자
- 금액은 1원 ~ 1조 원 **정수**

**검사 방식 : 마스크**

```python
valid_kind = clean["구분"].isin(['수입', '지출'])   # 행마다 True/False

if not valid_kind.all():                            # 하나라도 False면
    rows = [str(i + 1) for i in clean.index[~valid_kind]]   # ~ : 뒤집기 → 틀린 행 번호
    raise ValueError(f"... 잘못된 데이터 행: {', '.join(rows)}")
```

**`errors="coerce"`** : 변환 못 하는 값을 에러 대신 빈 값(NaT/NaN)으로 → `notna()`로 한꺼번에 검사

## 헷갈렸던 것

- **출력에 `[]`가 찍힘** → 함수 안에 디버깅용 `print(missing)`이 남아 있어서. 지우기.
- **에러 문장은 누가 정함?** → 전부 내가 `raise ValueError("...")`에 쓴 것. 파이썬은 에러 종류 이름만 정한다.
- **"지출를"** → `를`이 고정이라 받침 있는 단어에 어색함.
- **`pd.Serise`** → `pd.Series` 오타. 실행 안 된 줄이라 에러가 안 났을 뿐.
- **`and` 대신 `&`** → Series는 행마다 비교해야 해서 `&`, `|`, `~` 사용. 조건마다 괄호.
- **`.copy()`** → 원본 표가 같이 바뀌지 않게.
- **CSV 인젝션** → `=1+1`처럼 `= + - @`로 시작하면 엑셀이 수식으로 실행 → 앞에 `'` 붙이기.
