# 파이썬 오류(예외) 종류 정리

## 1. 자주 만나는 내장 오류

| 오류 | 의미 | 발생 예시 |
|---|---|---|
| `ValueError` | 자료형은 맞지만 **값**이 잘못됨 | `int("abc")` |
| `TypeError` | **자료형**이 잘못됨 | `"a" + 1` |
| `ZeroDivisionError` | 0으로 나눔 | `4 / 0` |
| `IndexError` | 리스트/튜플 **인덱스 범위** 초과 | `[1, 2, 3][3]` |
| `KeyError` | 딕셔너리에 없는 **키** | `{"a": 1}["b"]` |
| `NameError` | 정의되지 않은 **이름**(변수·함수) 사용 | `print(abc)` |
| `AttributeError` | 객체에 없는 **속성/메서드** 사용 | `[1, 2].push(3)` |
| `FileNotFoundError` | 존재하지 않는 **파일** 열기 | `open("없는파일", 'r')` |
| `ModuleNotFoundError` | 존재하지 않는 **모듈** import | `import abcde` |
| `NotImplementedError` | 아직 **구현 안 됨** (일부러 발생시킬 때 사용) | `raise NotImplementedError` |
| `SyntaxError` | **문법** 오류 (실행 전에 발견, try로 못 잡음) | `if x == 1 print(x)` |
| `IndentationError` | **들여쓰기** 오류 | 들여쓰기 깨진 코드 |
| `Exception` | 모든 일반 오류의 **부모** | `except Exception:` → 대부분의 오류를 잡음 |

> 전체 목록 보기: `print(dir(__builtins__))` → `~Error`로 끝나는 이름들

## 2. 에러 메시지 읽는 법

```
Traceback (most recent call last)
Cell In[8], line 5            ← 내가 호출한 곳
----> 5 eagle.fly()
Cell In[7], line 4            ← 실제로 오류가 난 곳
----> 4     raise NotImplementedError
NotImplementedError:          ← 오류 종류 : 메시지
```

- **맨 아래 줄**을 먼저 본다 → 오류 종류와 메시지
- 위로 올라가며 **어디서 호출됐는지** 추적한다

## 3. 오류 처리 문법

```python
try:        # 오류가 날 수 있는 코드
except:     # 오류가 나면 실행
else:       # 오류가 안 나면 실행
finally:    # 무조건 실행
```

```python
try:
    x = int(input("숫자: "))
    print(10 / x)
except ZeroDivisionError:                 # 특정 오류 하나
    print("0으로 나눌 수 없습니다.")
except (ValueError, TypeError) as e:      # 여러 오류 묶기 + 메시지 받기
    print("잘못된 입력:", e)
```

- `try` 안에서는 **처음 발생한 오류 하나만** 잡히고, 그 뒤 줄은 실행되지 않음
- `except: pass` → 오류를 조용히 무시 (가능하면 구체적인 오류 이름을 적을 것)

## 4. `raise` : 오류를 일부러 발생시키기

```python
raise 오류종류
raise 오류종류("메시지")
```

```python
def set_age(age):
    if age < 0:
        raise ValueError("나이는 음수일 수 없습니다")
```

### raise 뒤에 올 수 있는 것
| 가능 여부 | 예시 | 결과 |
|---|---|---|
| ✅ 내장 오류 | `raise ValueError` | `ValueError` 발생 |
| ✅ 직접 만든 오류 | `raise MyError` | `MyError` 발생 |
| ❌ 정의 안 된 이름 | `raise nonon` | `NameError: name 'nonon' is not defined` |
| ❌ 문자열 | `raise "오류"` | `TypeError: exceptions must derive from BaseException` |

- 적은 오류가 **그대로** 발생함 (`raise ZeroDivisionError`는 실제로 나누지 않아도 발생)
- 그러니 **상황에 맞는 이름**을 골라야 나중에 원인을 바로 찾을 수 있음
- 함수 안의 `raise`는 **정의할 때가 아니라 호출할 때** 실행됨

## 5. 오류 직접 만들기

`Exception`을 **상속**해야 파이썬이 오류로 인정한다.

```python
class MyError(Exception):
    def __str__(self):                 # print(e) 했을 때 나올 메시지
        return "허용되지 않는 별명입니다."

def say_nick(nick):
    if nick == '바보':
        raise MyError()
    print(nick)

try:
    say_nick("바보")
except MyError as e:
    print(e)          # 허용되지 않는 별명입니다.
```

## 6. 상속 + raise : 자식에게 구현 강제하기

```python
class Bird:
    def fly(self):
        raise NotImplementedError    # 자식이 fly를 안 만들면 오류

class Eagle(Bird):
    pass
Eagle().fly()     # 부모의 fly가 실행됨 → NotImplementedError

class Eagle(Bird):
    def fly(self):                   # 오버라이딩
        print("very fast")
Eagle().fly()     # very fast
```

- 자식에 fly가 없으면 **부모의 fly를 찾아서 실행**함 (상속은 정상)
- 그런데 부모 fly의 내용이 `raise`라서 오류가 남
